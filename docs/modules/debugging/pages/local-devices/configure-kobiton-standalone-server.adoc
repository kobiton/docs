= Configure Mac mini hosts for Hybrid or Standalone
:navtitle: Configure Mac mini hosts for Hybrid or Standalone

For Hybrid and Standalone/On-Prem deployments, organization admins enable virtualUSB for each Mac mini host from Device Management in Kobiton Portal. Editing the `dc.ini` file on the Mac mini host is no longer required.

== Requirements

* An account with the *ADMIN* predefined role

== Enable virtualUSB on the Mac mini hosts

For each Mac mini host, follow the steps in xref:device-lab-management:deviceConnect/enable-virtualusb-for-host-machines.adoc#_enable_virtualusb_on_a_host_machine[Enable virtualUSB on a host machine,window=read-later]. Set the network routing for your deployment:

* *Hybrid*: select a *Network Routing* option. See xref:device-lab-management:deviceConnect/enable-virtualusb-for-host-machines.adoc#_network_routing_options[Network routing options,window=read-later].

* *Standalone/On-Prem*: enter the IP address that end users' machines use to reach the Mac mini host in *Connection Address*. The *Network Routing* column is not shown.

After you save, users in your organization can use virtualUSB for private or local devices on those Mac mini hosts.
