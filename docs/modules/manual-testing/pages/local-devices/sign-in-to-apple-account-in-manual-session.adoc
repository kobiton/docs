= Sign in to an Apple Account during a manual session

During a manual iOS session, Apple disables the device's virtual keyboard for protected sign-in fields, such as the password and verification code. Use the *Apple Security Enablement* window in Portal to enter these values.

NOTE: Apple Account sign-in is available on private and local iOS devices only.

== Sign in to an Apple Account

. On the device screen, open *Settings*, then tap *Apple Account*.
. Tap *Sign in Manually*.
. Tap *Email or Phone Number*, type or paste the Apple Account email address, then press Enter.
+
The *Password* field appears, and the *Apple Security Enablement* window opens in Portal.
. In the *Apple Security Enablement* window, click the *Password* field, type or paste the password, then click *Submit*.
+
image:manual-testing:enter-appleid-pw.png[width=400, alt="The Apple Security Enablement window next to the Apple Account password field on the device screen"]
. Close the *Apple Security Enablement* window.
. Swipe up on the device screen, then tap *Continue*.
. When the *Apple Account Verification Code* prompt appears, get the six-digit verification code from a trusted device signed in to the Apple Account.
. Type the code in the *Apple Security Enablement* window, then click *Submit*.
+
image:manual-testing:enter-verification-code.png[width=400, alt="The Apple Security Enablement window next to the Apple Account Verification Code prompt on the device screen"]
+
After a few seconds, the window and the prompt close, and sign-in continues.
. If the *Enter Mac Password* prompt appears, use the password for the Mac named in the prompt, not the Apple Account password. Type it in the *Apple Security Enablement* window, then click *Submit*.
+
image:manual-testing:enter-mac-pw.png[width=400, alt="The Apple Security Enablement window next to the Enter Mac Password prompt on the device screen"]
. Follow the remaining prompts on the device screen.

When the Apple Account name and email address appear on the device screen, sign-in is complete.
