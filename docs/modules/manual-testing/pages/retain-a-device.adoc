= Retain a device
:navtitle: Retain a device

Retaining a device reserves it for your exclusive use for a set duration. While a device is retained, no one else in your organization can start a session on it, and the cleanup policy (if active) does not run between your sessions.

You can retain a device when you exit a manual session, or retain a private or local device from the device list without starting a session.

== Retain a device when you exit a session

. In your manual session, select *Exit current session*. Portal opens a confirmation prompt.
. Open the *Retain* dropdown and select a duration.
. Select *Exit Session*.

To stay in the session, select *Continue Session* instead.

== Available durations

The *Retain* dropdown on the exit prompt offers these durations:

* *Do not retain device* (default)
* *Unlimited*
* *1 hour*
* *2 hours*
* *4 hours*
* *8 hours*
* *24 hours*

[NOTE]
The device-list *Retain* dropdown does not include *Do not retain device*. See xref:devices:manage-devices.adoc[].
