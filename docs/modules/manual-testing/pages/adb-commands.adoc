= adb shell commands
:navtitle: adb shell commands

These are the Android Debug Bridge (`adb`) shell commands you can xref:manual-testing:device-controls.adoc#_adb_shell[run during a manual session], which includes installing apps, managing permissions, analyzing performance, and more. The commands are available for Android devices.

image:manual-testing:adb-shell-context.png[width=1000, alt="A manual session with the `adb` shell open."]

== Public devices

// Source: KOB-54718
Public devices run a restricted shell. The same restriction applies to every device used by a trial account. Each command is checked before it reaches the device, and some dangerous operations are rejected. A rejected command returns a message stating that shell access on this device is restricted. The device stays online and the session continues.

Read-only diagnostic commands run normally. For example:

* `dumpsys display`
* `dumpsys battery`
* `getprop ro.build.version.release`
* `pm list packages -3`
* `settings get secure enabled_accessibility_services`

The restriction applies wherever you reach the shell on a restricted device:

* the *adb shell* control in a manual session
* the manual view of a xref:automation-testing:start-a-mixed-session.adoc[mixed session]
* the xref:kobiton-cli:cli-commands.adoc#adb-shell-restricted-sessions[`kobiton device shell`] CLI command

== Private and local devices

You can run most `adb` commands on private and local devices--as long as they don't harm the device or alter systems in real-time.

The following commands are blocked entirely:

* `kobiton`
* `logcat`
* `monkey`
* `top`

Destructive operations against the following protected packages are blocked. This includes `pm uninstall`, `pm clear`, and `am force-stop`. You can still launch these packages with `am start`, `am start-activity`, `am start-service`, or `am start-foreground-service`.

* `com.domobile.applock`
* `com.domobile.applockwatcher`
* `com.sp.protector.free`
* `com.manageengine.mdm.android`
* `com.manageengine.mdm.samsung.knox`
* `com.manageengine.mdm.samsung`
* `com.manageengine.admp`
* `com.android.systemui`
* `com.android.settings`
* `com.android.vending`
* `com.google.android.webview`
