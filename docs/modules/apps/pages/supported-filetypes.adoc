= Supported app filetypes and size
:navtitle: Supported app filetypes and size

These are the supported filetypes for uploading apps to the xref:apps:manage-apps.adoc[app repository].

== File size

The maximum file size for app upload is *4GB*. This applies to:

* both Android and iOS apps.
* all app filetypes.

== iOS

=== `.ipa`

A standard package containing your app and related resources.

=== `.zip`

A standard `.zip` file containing a compressed version of your iOS app and related resources.

=== `.app`

An iOS app bundle built either for iOS Simulator or for real iOS devices. Compress the `.app` bundle to a `.zip` file before uploading. Upload the compressed file as a `.zip` file, or as a `.app` file that is a `.zip` archive.

`.app` uploads are supported from the app repository, API v2, and the Kobiton CLI. If you select an uncompressed `.app` in the app repository, a message asks you to compress it first.

During a manual session, a zipped `.app` can also be installed from *Install Apps* on real iOS devices and iOS Simulators. For details, see xref:manual-testing:install-an-app.adoc#_ios_build_types[iOS build types].

The build type is determined by the `DTPlatformName` value in the app's `Info.plist`:

* `iphonesimulator`: iOS Simulator build.
* Any other value, or no value: device build.

Simulator builds can't be installed on real devices, and device builds can't be installed on iOS Simulators.

== Android

=== `.apk`

A standard package containing your app and related resources.

=== `.aab`

An Android App Bundle (AAB) containing your app and related resources that defers `.apk` generation and signing to Google.
