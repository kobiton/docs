== Improvements and fixes

=== Scriptless Test Runs

- For Test Cases converted from automation sessions, Camera Roll now names each automation test step by its WebDriver endpoint path, matching the names on the Test Case Details page. The *Baseline Screenshot* and *Revisit Screenshot* panels both use the endpoint path. Previously, these steps showed a generic *Auto Command* label.
- Camera Roll shortens an endpoint path that does not fit the step card. Hover over the name to see the full path.
