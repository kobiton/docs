=== New report: Individual Sessions

- Available under *Analytics Reports* in the Portal to organization ADMINs only, in the *Usage* group.
- The report lists every session started within the selected date range, one row per session, including session timing, user, team, device details, session minutes, type, and state.
- The date range defaults to the last 7 days.
- Filter by *Date Range*, *Team*, or *User Email*. *User Email* accepts multiple addresses and searches the full user list as you type.
- The table displays up to 100,000 rows. For larger result sets, narrow the filters or export the report to CSV.

See xref:reporting:individual-sessions-report.adoc[].
