== Kobiton CLI

- Fixed `kobiton file push` and `kobiton file pull` reporting success and exiting `0` when the transfer failed on the device. A push to a path the device refuses, a push to an iOS app that is not installed, and a pull of a file that does not exist now exit with a non-zero status. This applies to iOS devices, iOS simulators, and Android devices.
- Fixed `kobiton file push` to iOS devices and iOS simulators intermittently failing with an error even though the file was written.
