== HarmonyOS devices in the device list

The device list now recognizes HarmonyOS devices alongside iOS and Android devices.

- HarmonyOS devices display a HarmonyOS icon in List View and the *Remove unused devices* window.
- Device cards show the platform and OS version, such as `HarmonyOS 6.0.0`.
- A *HarmonyOS* platform filter shows only HarmonyOS devices and displays the number of HarmonyOS devices. The filter appears only when your organization has at least one HarmonyOS device.
