== Device passcode

- Devices now have a passcode set before they return to *Available*. Previously, in organizations that use a cleanup policy with passcode enabled, a device could return to *Available* after cleanup without a passcode, and the next session started on an unlocked device.
- On devices enrolled in an MDM that requires a passcode, those sessions started with the MDM passcode prompt. Sessions on affected devices now start as expected.
