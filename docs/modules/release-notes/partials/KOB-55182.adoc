== Device passcode

- Fixed devices becoming available without a passcode after a session ended. On organizations that use passcode mode with a cleanup policy, cleanup removed the device passcode after Kobiton had set it, so the next session started on an unlocked device. On devices managed by a mobile device management (MDM) solution, that session opened to an MDM prompt requiring a passcode. Kobiton now sets the passcode after cleanup completes, so the device has a passcode before it becomes available.

_Applies to organizations that use passcode mode with a cleanup policy._
