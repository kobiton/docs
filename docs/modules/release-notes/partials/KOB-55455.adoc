== iOS simulator session fixes

- Fixed an issue where changing the device language in a manual session on an iOS 27 simulator ended the session about 60 seconds later. The viewer now shows *Device agent is recovered* after the language change, and you can continue testing in the new language.
- The session can pause for up to 120 seconds while the device agent restarts after a language change. If the agent cannot restart on an iOS simulator, the session now ends after up to 120 seconds instead of 60 seconds. Real devices are unchanged.
