== Cleanup on iOS Simulators

Cleanup now erases an iOS Simulator and returns it to its default state, instead of running the individual cleanup configurations.

*Highlights*

- Apps installed during the session, app data, Safari history and tabs, and Settings changes are removed when cleanup runs.
- The erase runs every time cleanup runs on a simulator, on any iOS version. The individual configurations in a cleanup policy don't apply to simulators. The _No Cleanup_ policy still skips cleanup.
- Time zone and locale return to the simulator's defaults.
- The simulator becomes available again without action on the host. Real iOS devices keep the cleanup configured in their policy.

For details, see xref:devices:local-devices/cleanup-policy/cleanup-configurations.adoc#_ios_simulators[iOS Simulators].
