== Appium automation

- On iOS Simulators, `mobile: queryAppState` and `mobile: isAppInstalled` now return the app state and installed status. Previously, both commands failed with a server error for every bundle ID, so scripts that waited for an app to reach the foreground, or checked whether an app was installed before installing it, stopped on simulators. Both commands now return the same values as on a real iOS device, including after `mobile: activateApp` and `mobile: terminateApp`.
