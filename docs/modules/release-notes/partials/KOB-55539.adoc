== Improved session reliability

Fixed an issue where one unresponsive session could stop every other session on the same host. Until the host was restarted, new sessions could not start on it, Appium and mixed sessions on it failed, and active sessions could not end.

- An unresponsive session no longer blocks other sessions or new session creation on the same host.
- An Appium or REST API request to a session that cannot accept more requests now fails immediately with HTTP `503` and the message `Session <session-id> is busy. Retry later`. Previously, the request waited without a response.
- No configuration change is required.
