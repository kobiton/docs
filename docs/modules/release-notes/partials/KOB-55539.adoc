== Session reliability

- Fixed an issue where one unresponsive session could block other sessions on the same host. Previously, new sessions could not start, automation sessions failed, and active sessions could not end until the host was restarted.
- Appium commands and other requests sent to a session that cannot keep up now fail right away with an HTTP `503` response instead of hanging. Retry the request later.
