=== Analytics reports

- Fixed an issue where exporting the *Device Utilization*, *Parallel Sessions*, and *Sessions per Day* reports as CSV or PNG returned no data. The CSV showed an export error in place of the report data.
- CSV exports of *Parallel Sessions* and *Sessions per Day* list one row per day in date order. CSV exports of *Device Utilization* sort by *Sessions*, with the most-used devices at the top.
- PNG exports of *Parallel Sessions* and *Sessions per Day* now include the report's chart as a bar chart. Previously, the PNG showed only the report title for these reports.
- Exports use the date range selected for the report, or the report's saved date range when none is selected.
