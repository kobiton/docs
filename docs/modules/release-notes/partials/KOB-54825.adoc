== Session recording

- A manual or automation session on an iOS device that cannot source high-quality video now falls back to screenshot-based recording, so the session ends with a video attached to its detail page. Previously, sessions on an affected device ended with no recording, and the session detail page had no video.

[NOTE]
====
The fallback recording is short and low frame rate by design. Lightning Mode does not activate on an affected device, and the device must be rebooted to source full-quality video again.
====

_Applies to iOS devices in a state where video capture is blocked. The state persists across sessions and clears only after a device reboot._
