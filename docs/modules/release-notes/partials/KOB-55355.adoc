== Inspector and element search on Android devices

- Fixed an issue on Android 13 and later where the Inspector did not display the XML hierarchy for some screens that contain a web view. Element searches on these screens also failed in manual sessions and automation scripts. The Inspector now loads the full XML hierarchy for these screens, and scripts can find and interact with their elements.
