=== Private mode keeps private data out of automation session records

While `kobiton:privateMode` is on in a Xium or Appium 2 Basic automation session, data from that part of the session is not recorded. This includes commands, session video, screenshots, view trees, WebDriver request and response bodies, Appium and Xium logs, device logs, system metrics, and network capture. Errors are still returned to the script, and crash logs are still collected.

* Turn on private mode when the session starts with the `kobiton:privateMode` capability, or turn it on and off during the session with the `Update Settings` Appium command.
* The session video skips the private part of the session.
* Recording resumes when private mode is turned off.
* Sessions that do not turn on private mode are recorded as before.

For details and limitations, see xref:automation-testing:scripting/obfuscate-private-data-in-appium-script.adoc[Obfuscate private data in Appium script].
