== Lightning mode after a device language change on iOS

- In manual sessions on iOS and iPadOS devices, Lightning mode now resumes after the device language is changed to a language other than English. Previously, the session showed only lower-frame-rate screenshots for the rest of the session, even after *Lightning Mode* was turned on again. Screenshots are shown while the device stream restarts.
- If Lightning mode does not resume on its own, turn *Lightning Mode* on again to restore the device stream. On devices running iOS 16, Lightning mode does not resume on its own after a language change, so turn *Lightning Mode* on again each time.
