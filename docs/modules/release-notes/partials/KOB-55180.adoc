== virtualUSB

- When you connect to a device on a host machine that has reached its *Max Parallel Tests* limit, the virtualUSB desktop app and the virtualUSB CLI now show _Host has reached its configured capacity. Please try again later._ This matches the message shown in the Portal. Previously, virtualUSB showed a generic session failure that did not mention host capacity.
