=== deviceConnect

* Fixed an issue where the device list in deviceConnect Console could stop loading. The issue occurred when an iOS device repeatedly failed to start and a newer provisioning profile from a different Apple Developer team was installed. Each retry re-signed the agent apps again instead of reusing the existing signed copy, which slowed the device list and API requests until they stalled. deviceConnect now reuses the signed copy unless a newer provisioning profile is available.
* Improved provisioning profile selection when re-signing iOS apps. deviceConnect can now re-sign an app with a newer provisioning profile from a different Apple Developer team than the one the app was last signed with. Provisioning profiles that lack a capability the app requires are still not used.
