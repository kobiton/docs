== API v2

- Fixed device lookups by UDID for virtual devices. `GET /v2/devices/udid/{udid}` now returns device information for Android emulators and iOS simulators that your organization can use. Previously, the request returned `404` for an online virtual device.
- `GET /v1/devices/{udid}` also returns these virtual devices. Previously, it returned `500`.
- Lookups for physical devices and unknown UDIDs are unchanged. Organizations without access to virtual devices continue to receive `404` for virtual device UDIDs.
