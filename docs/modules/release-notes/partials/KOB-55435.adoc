== Kobiton MCP server

- The Kobiton MCP server's tool list now ships with each release. Every environment serves the tool definitions that were tested with its release, and the tools are available as soon as the server starts.
- Removed the `uploadAppForRunner` and `listDeviceBundles` tools. Neither tool appeared in the server's tool list, and calls to them return a `Method not found` error.
