=== Standalone deployment

- On Standalone deployments with GPUs, Intelligent Quality Suite (IQS) AI services now keep GPU access after system package installs, such as a GigaCap install or upgrade. Previously, these services could switch to the CPU, and IQS element finding slowed down and timed out.
- Installing or updating Standalone now stops with an error if a configured GPU ID does not match a GPU on the host. Previously, the install continued without reporting the problem.
- After you update, the IQS AI services restart once to apply the new GPU configuration.
