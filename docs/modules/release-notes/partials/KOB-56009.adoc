== Manual sessions

- Fixed an issue on iOS devices in Lightning Mode where selecting the screen recording indicator in the status bar froze the live view for close to a minute before the device's stop-sharing dialog appeared. The live view now switches to screenshots right away and shows the dialog. Select *Cancel* to return to the device's video stream. If you select *Stop*, the session continues on screenshots until the video stream restarts.
