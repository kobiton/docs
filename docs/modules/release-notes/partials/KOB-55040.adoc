== Appium automation

- Automation sessions that use `appium:autoWebview` on Safari now recover automatically from a lost web-inspector connection. A device that could not previously return a web context, for example after *Settings > Safari > Advanced > Web Inspector* was toggled off and back on, now attaches to a valid page on the next session without a manual reboot or manual Safari setup. Previously, an affected device kept failing every session with `Unable to find any web views` until it was physically rebooted.
