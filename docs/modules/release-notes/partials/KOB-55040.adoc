== Web context recovery for iOS sessions

- iOS sessions now refresh the device web inspector connection as the session starts. A device that has stopped reporting web contexts recovers on its next session, with no manual step on the device.
- This applies to every iOS session that reads a web context, including `appium:autoWebview` setup, Safari automation, and the web portion of the view tree capture.
- Previously, once a device entered this state, every later session on that device failed at setup with `Unable to find any web views`, and rebooting the device was the only way to clear it.
- A connection that breaks during a session stays unavailable for the rest of that session. The next session on that device starts with a working connection.
- Android sessions are unchanged.
