== Analytics reports

- A new *Retained Devices* report is available under *Analytics Reports* in the Portal. The report lists retained devices, who retained them, how long each device has been retained, and the last time each device was used.
- Columns include *Device Model*, *OS*, *State*, *Retained By*, *Retaining User's Team/Group*, *Retain Start*, *Retain End*, *Last Session*, *Last Used*, and *UDID*.
- Filter results by *Retained by email* or *UDID*, and search for a team from the table's search box.
- Results sort by *Last Used*, with the longest-idle devices at the top.

_Available to organization admins in every organization._
