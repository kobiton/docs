== Kobiton Status Page link available on Private Cloud

The help widget on some Private Cloud deployments now includes a *Kobiton Status Page* link. Select it to check service status at https://status.kobiton.com/[status.kobiton.com^], which opens in a new tab.

- The link appears after *Support* in the help widget, in the same position as on Kobiton Public Cloud.
- If the link is not shown, it is not enabled for your Private Cloud deployment.
- The link is not available on Standalone deployments.

See xref:help-widget:index.adoc[].
