// iPad passcode is set again after a device language change.
// Target section on the release page: == Device passcode (or the page's device fixes section)
// Draft staged by Robot Ranch. Not yet included in a release page.

- Fixed an issue where an iPad with a device passcode could return to *Available* without its passcode after the device language was changed during a session. The passcode is now set again before the device is available to users. Mobile device management (MDM) tools no longer flag these iPads as having no passcode after a language change.
