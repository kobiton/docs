== iOS UI hierarchy

- Fixed an issue where an iOS session could keep reading the UI hierarchy of an app that was no longer in the foreground. After the foreground app changed, element searches could run against the previous app, or against the home screen or app switcher, while a different app was on screen, and the outdated hierarchy could persist for the rest of the session. The UI hierarchy now reflects the app in the foreground.
