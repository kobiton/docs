== Appium automation fixes

- Fixed an issue in Android native app sessions where the WebDriver Get Element Attribute command returned an error when you requested an attribute the element doesn't have, such as `value`. The command now returns `null`, as the W3C WebDriver specification requires, and the session remains usable. Known attributes such as `text`, `enabled`, and `checked` still return their values, and a request for a stale element still returns an error.
