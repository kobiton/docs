== Kobiton MCP server

- New: the `automate` MCP plugin adds a `listResponseTimeValidations` tool that returns a session's response time validations. Each entry covers one command that ran slower than its target response time and reports the command id, the actual response time in milliseconds, and the target response time in milliseconds.
- Results are paged. `limit` defaults to 10 and accepts a maximum of 20, and `offset` defaults to 0. Each response carries the page number, the total page count, and the total item count alongside the returned items.
- A session with no commands over the target returns a total of 0 items and an empty list rather than an error.
