== iOS simulators

- Automation sessions that request Safari (`browserName: Safari`) on an iOS simulator are now refused at session start with the message `Web testing is not supported on iOS simulators. Please use a real iOS device.` Previously, these sessions failed with an internal error that did not state the cause. Web testing remains unsupported on iOS simulators. Run web tests on a real iOS device.
