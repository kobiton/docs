== iOS simulators

- Fixed an issue where automation sessions that request Safari (`browserName: Safari`) on an iOS simulator failed with an internal error that did not state the cause. Kobiton now refuses these sessions at start with the message `Web testing is not supported on iOS simulators. Please use a real iOS device.` The simulator stays available for other sessions. To run web tests, use a real iOS device.
