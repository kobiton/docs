== Redrawn fold and unfold icons

The fold and unfold icons in the manual session toolbar and the Session Explorer timeline are redrawn so they are easier to recognize at 100% browser zoom.

* When the device is unfolded, the toolbar shows the new *Fold device* icon. When the device is folded, the toolbar shows the new *Unfold device* icon. Tooltips and fold behavior are unchanged.
* The toolbar icon is a darker gray, and the entire icon changes color on hover and while pressed.
* *FOLD DEVICE* and *UNFOLD DEVICE* steps in the Session Explorer timeline use the same icons.

For details, see xref:manual-testing:device-controls.adoc#_fold_or_unfold_device[Fold or unfold device].
