== HarmonyOS sessions labeled correctly in Sessions

*Sessions* now identifies HarmonyOS sessions as HarmonyOS instead of iOS.

- The session list shows the HarmonyOS icon and OS label, and the device manufacturer, such as HUAWEI, instead of Apple.
- Search suggests `os:harmonyos`, and the `os:harmonyos` query returns only HarmonyOS sessions.

Android and iOS sessions are unchanged.
