== deviceConnect runs on .NET 11

deviceConnect now runs on .NET 11 on macOS and Linux hosts.

* The macOS installer includes the .NET runtime instead of the full .NET SDK, which makes the installer about 300 MB smaller.
* Updating deviceConnect on an existing host moves it to .NET 11.
