== Bluetooth Bridge: static IP address setup without a monitor

- Added an option to assign a static IP address to a new Raspberry Pi host without connecting a monitor. Starting with the 4.24 Bluetooth Bridge system images, after you flash the image to an SD card, mount the SD card on your computer and edit the `network-config` file before you start the Raspberry Pi host. The `network-config` file uses the netplan format. The current static IP setup method continues to work. Keep a monitor available in case the network configuration does not apply.
