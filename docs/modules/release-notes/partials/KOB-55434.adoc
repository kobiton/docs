== Appium automation fixes

* Fixed an issue where Appium automation sessions on iOS simulators failed to start. When the `kobiton:runtime` capability was set to `appium`, the session request returned a `TaskCanceledException` error after about 3 minutes. Appium sessions on iOS simulators now start, and the simulator stays booted for the sessions that follow.
