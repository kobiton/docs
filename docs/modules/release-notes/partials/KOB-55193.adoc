== iOS device connectivity

- Fixed an issue where iOS 17 and later devices on macOS hosts in Standard mode stayed offline after a restart. This happened when deviceConnect enabled Developer Mode on the device, when the device was rebooted, or when the device cable was reconnected. Previously, the device remained offline until deviceConnect was restarted. Lightning mode hosts were not affected.
