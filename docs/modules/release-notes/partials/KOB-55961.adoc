== Session updates through the Kobiton API take effect immediately

Changes to a session's name, description, or state made with `PUT /v1/sessions/{id}` or `PUT /v2/sessions/{id}` now take effect before the request returns. Previously, the updated values could take 30 seconds or longer to appear.

* *Session details:* After the request returns `200`, retrieving the session returns the new name, description, and state (`PASSED` or `FAILED`) right away.
* *Session state:* A new `PASSED` or `FAILED` state takes effect immediately once the session has ended.
* *Session lists, search, and reports:* The new state appears without additional delay.
