== Kobiton API: session updates take effect immediately

- Updates to a session's name, description, or state through `PUT /v1/sessions/{id}` or `PUT /v2/sessions/{id}` now take effect before the request returns. After the request returns HTTP 200, `GET /v1/sessions/{id}` and `GET /v2/sessions/{id}` return the new name, description, and state right away. Previously, the change could take 30 seconds or longer to appear.
- A `PASSED` or `FAILED` state takes effect immediately only for a session that has ended. Session lists, search, and reports show the new state without additional delay.
- `PUT /v1/sessions/{id}` continues to accept a state while the session is running, for example a state set just before the script ends the session. That state is saved shortly after the request returns, as before.
