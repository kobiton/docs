=== Standalone deployment

- Added `sudo kobictl fix consul-server-metadata`. It repairs an unreadable Consul server metadata file that stops Consul from starting with `error reading server metadata: unexpected end of JSON input`. The fix prints the file size and contents, removes only that file, and restarts Consul. Other Consul data is kept. If the file is valid or missing, the command makes no changes.
- `sudo kobictl restart` now runs the same check automatically after each restart.
