== Install Apps lists only compatible builds on iOS

*Install Apps* in a manual session now lists only the app builds that can install on the current iOS device.

*Highlights*

- On an iOS Simulator, only simulator builds (`.app`) are listed. On a real iOS device, simulator builds are hidden.
- *Upload File* and *Install From URL* accept a `.app` compressed to a `.zip` file on iOS Simulators.
- Android sessions are unchanged.

For details, see xref:manual-testing:install-an-app.adoc#_apps_listed_on_ios[Apps listed on iOS].
