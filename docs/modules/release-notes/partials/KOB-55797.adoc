== Network payload capture

- Fixed an issue where a network capture profile that failed to load opened as an empty, editable form with no error. Saving that form replaced the stored profile's name, Capture Filter, and content types with the values entered.
- When you edit a network capture profile, *Save* is available only after the profile loads. If the profile can't be loaded, the message "Could not load this Network Capture Profile. Reload the page to try again." appears and *Save* stays disabled.
