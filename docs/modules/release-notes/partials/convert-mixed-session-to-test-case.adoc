=== Convert a mixed session into a Test Case

Completed mixed sessions can now be converted into Test Cases, extending the flow already available for manual and Appium automation sessions. The converted Test Case holds the manual steps and the automation steps in the order they were recorded, so a combined flow can be rerun without recreating the session.

*Highlights*

- A mixed session must be complete before it can be converted. Sessions that are still running are not eligible.
- The Test Case preserves the original recorded order across the manual and automation steps, and tags each step with its source.
- Convert from Session Explorer or from the *+New Test Case* pop-up on the Test Cases list page. Search for eligible sessions with `type:mixed`.
- Test Cases converted from a mixed session show *Mixed* as the Source type.
- A Revisit replays each step through the execution path that matches its source and reports per-step results. Steps with no replayable equivalent, such as an unsupported Appium endpoint, are skipped with a reason and the run continues.
- Appium script generation is not available for Test Cases converted from mixed sessions.
