== iOS simulators

* Fixed an issue where restarting an iOS simulator sometimes left it shut down and *Offline*. This affected restarts from the *Restart* option in Kobiton Portal and from the Kobiton CLI `device restart` command. The simulator stayed unavailable until someone started it again on the host machine. A restarted simulator now comes back *Online* with the same UDID.
