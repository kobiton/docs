=== Manual testing

- Fixed an issue where *Set device timezone* failed on iOS simulators in manual sessions and showed `Cannot set the device time zone. Please try again.` You can now change the time zone of an iOS simulator from the session toolbar, and the simulator's status bar clock shows the new time zone.
- Each time zone change on an iOS simulator pauses the simulator screen for several seconds and closes the app in the foreground. Relaunch the app to continue testing.
- When the cleanup policy resets the time zone after a session, iOS simulators now return to the time zone of their host.
