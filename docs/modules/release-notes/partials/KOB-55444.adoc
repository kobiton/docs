== iOS device connections

- Fixed an issue where deviceConnect could intermittently fail to mount the Developer Disk Image (DDI) on newer iOS devices, such as iPhone 18 models running iOS 26.4 or later. DDI mounting on these devices also no longer fails when a disk image is already mounted on the device.
