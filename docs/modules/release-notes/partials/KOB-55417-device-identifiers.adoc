== Read device identifiers in automation scripts

Xium automation sessions now support the `mobile: deviceIdentifiers` command, which returns the advertising and tracking identifiers a device holds. Use it to compare the identifiers your app reports with the values on the device.

* *Advertising ID:* Read the IDFA on iOS and the AAID on Android. On iOS, the response also includes the app tracking status.
* *Android ID:* Read the Android ID (SSAID) along with the signing certificate it belongs to.
* *DRM ID:* Read the DRM ID of an Android app that is a debug build and is running.

The identifier for vendor (IDFV) on iOS is not supported.

For details, see xref:automation-testing:scripting/read-device-identifiers-in-appium-script.adoc[].
