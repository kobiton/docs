== Readable device details for iOS Simulator sessions

In the session *Overview* for an iOS Simulator session, a long *Model Name* value, such as `com.apple.CoreSimulator.SimDeviceType.iPhone-16`, now wraps within its own column in the *Virtual Device Info* card. Previously, the value ran into the *UDID* column, and the two values overlapped and couldn't be read.

The *UDID* hover tooltip and copy behavior are unchanged.
