== Separate text and vision models in Appium AI settings

The *Appium AI Configuration* form for organization settings now sets the text model and the vision model separately.

* The form shows *Text Model* and *Vision Model*, plus *Text Extra Body* and *Vision Extra Body*. *Save* stores all of them, regardless of the selected locator strategy.
* *Locator Strategy* is now *Default Locator Strategy*. A session can still override it with the `kobiton:locatorStrategy` capability.
* *Optional Fields* now lists only fields you can leave blank.
* The *Appium AI* card on the *AI Settings* tab shows the API format and both models.

For details, see xref:automation-testing:appium-ai/configure-appium-ai-org-settings.adoc[Configure Appium AI settings for your organization].
