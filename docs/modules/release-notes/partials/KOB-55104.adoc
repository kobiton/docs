== App installation

- Installing an app during a session no longer leaves a full-size copy of that app in temporary storage on the host machine. Previously, every install wrote a copy that was never removed, so installing a series of different apps consumed host disk space until deviceConnect restarted. Once temporary storage filled, later installs failed with `Failed to install the application on the device` and `No space left on device`.
- Installing an iOS app no longer expands the entire `.ipa` on the host machine to read the app's metadata.
- Installing an app from the Apps repository now uses no additional temporary storage on the host machine. Install behavior is otherwise unchanged on iOS and Android.

[NOTE]
====
Copies left in temporary storage by earlier releases are removed when deviceConnect restarts.
====

[NOTE]
====
On iOS, the first install of an app that Kobiton re-signs still uses temporary storage while re-signing runs. This release does not change that.
====
