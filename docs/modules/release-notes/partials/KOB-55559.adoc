=== Sessions continue during infrastructure scaling and updates

Appium Turbo Test sessions that are running when Kobiton scales down or updates its test execution infrastructure now run to completion instead of being terminated. Results and test reports from these sessions remain available as usual.

During these events, new Turbo Test sessions start on other available infrastructure.
