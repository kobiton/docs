== Basic Appium 3 sessions and updated Appium 2 drivers

Basic Appium 3 is now available alongside basic Appium 2. Appium 3 is opt-in only: a session uses Appium 3 only when `kobiton:runtime` is set to `appium3`. This release also updates the drivers for basic Appium 2, including major version updates to the XCUITest and UiAutomator2 drivers. Driver updates can change command or capability behavior, so test existing basic Appium 2 scripts after this release.

*Highlights*

* Set `kobiton:runtime` to `appium3` to run a session on Appium 3. See xref:automation-testing:basic-appium-server/launch-a-basic-appium-3-session.adoc[Launch a basic Appium 3 session].
* `appium2` is now accepted as a `kobiton:runtime` value. It selects the same basic Appium 2 runtime as `appium`.
* Scripts that use `appium` or `appium2`, and scripts that use the default Xium runtime, continue to run on their existing runtime.
* Basic Appium 2 and basic Appium 3 sessions can run at the same time on different devices.
* A session with an unrecognized `kobiton:runtime` value, such as `appium4`, is refused with an `Unknown runtime` error.
