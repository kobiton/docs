== Network Payload Capture options hidden for iOS Simulators

Network Payload Capture is not supported on iOS Simulators, so its configuration options no longer appear for iOS Simulators in *Devices*.

* The device details for an iOS Simulator no longer show the *Configuration* toggle and dropdown.
* In Card view and List view, the dropdown next to *Launch* no longer includes *Use custom configuration* for iOS Simulators. If *Use custom configuration* was the only option, only the *Launch* button appears.
* Launching an iOS Simulator from *Devices* never turns on Network Payload Capture, even if a configuration was selected earlier for another device.

Real iOS devices, Android devices, and Android emulators are unchanged.

For details, see xref:manual-testing:local-devices/capture-network-payload-data.adoc#_limitations[Network Payload Capture limitations].
