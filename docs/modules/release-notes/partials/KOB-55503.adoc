== Accurate per-step device logs for Kobiton CLI sessions

- Fixed an issue where per-step device logs for Kobiton CLI sessions appeared under the wrong step or were empty. Each step now shows the device log lines recorded since the previous step, and the first step shows the lines recorded before it.
