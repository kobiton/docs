=== New report: Mean Time Between Failure

- Available under *Reports* in Portal to Org Admins only, in the *Device* category.
- Measures the average time, in hours, that devices remain online and available between offline events. Higher MTBF values indicate greater device stability and reliability.
- Charts MTBF trends over time, summarized by week, for a date range you select.
- A week with no offline events shows an MTBF of 1000 hours. This value is a placeholder, not a measurement.
