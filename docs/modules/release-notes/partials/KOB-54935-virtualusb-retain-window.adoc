== virtualUSB

- The organization-level retain duration no longer applies to virtualUSB sessions. Every organization now uses the same window: a virtualUSB session ends after one hour without a check-in from the virtualUSB client.
- The client checks in every 10 minutes while it is connected, so a session in use is not affected. The hour counts only after the client stops checking in, for example when the host computer sleeps or loses its network connection.
