== AI plugin and MCP tools

- The Kobiton `automate` plugin adds the `listBlockerValidations` MCP tool, which lists the blocked steps from a session's revisit executions, newest first.
- Results are paged. `limit` defaults to 10 and is capped at 20, and `offset` sets where the page starts. Each response reports the total number of blocked steps recorded for the session.
- A session with no blocked steps returns an empty result instead of an error.
