== Device Management

=== Unified Settings dialog for host machines

Configure virtualUSB and Max Parallel Tests for every host machine from one *Settings* dialog in *Device Management*. The dialog replaces the per-machine *Settings* window.

*Highlights*

- The *Max Parallel Tests* tab sets a limit of *Unlimited* or a custom value between 1 and 999 for each host machine. The *All machines* row applies one setting to every host machine at once.
- Organizations whose plan includes virtualUSB also see a *virtualUSB* tab. Enable virtualUSB on specific host machines and set how connections are routed: *Managed by Kobiton* for Kobiton-hosted machines, or *Self-managed* with an editable IP address for machines hosted by your organization.
- Search by host machine name or IP address in both tabs. In the *virtualUSB* tab, select *Show enabled only* to list only enabled host machines.
- One *Save* applies changes from both tabs. If a save fails, the dialog stays open and keeps your changes. Closing the dialog with unsaved changes asks for confirmation.

*Availability*

Organization admins with the *ADMIN* predefined role. The *virtualUSB* tab requires a plan that includes virtualUSB.
