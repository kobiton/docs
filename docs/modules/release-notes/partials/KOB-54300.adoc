=== Network capture settings use profile naming

The settings for network payload capture now refer to profiles instead of configurations.

* The *Configurations* tab in *Settings* is now *Network Capture*.
* The listing page title is *Network Capture Profiles*, and the add button is *Add New Profile*.
* When no profiles exist, the empty-state message references the add button that appears on the page.
* Deleting a profile shows "profile" in both the confirmation dialog and the success message.

Existing profiles remain in the list with their names unchanged. Network payload capture behavior is unchanged.
