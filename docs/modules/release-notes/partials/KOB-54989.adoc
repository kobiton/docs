== Biometric authentication

- Biometric authentication in a manual session now completes within milliseconds on iOS 15 through 27. Previously, on the new deviceControl build, `Pass` and `Fail` responses timed out after approximately 60 seconds on every attempt, and the application under test remained in its waiting state indefinitely.

_Applies to manual sessions using applications that embed `KobitonLAContext.framework`._
