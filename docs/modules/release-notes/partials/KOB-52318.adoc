=== Lightning mode security update

Gigacap now includes libnice 0.1.24, the networking library that Lightning mode uses to connect to devices. This version fixes a heap overflow vulnerability in TURN relay connections over TCP.

Lightning mode sessions on iOS and Android devices work the same as before.
