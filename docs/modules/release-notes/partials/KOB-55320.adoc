== deviceConnect for Linux hosts (Android)

deviceConnect now runs on x64 Linux hosts for Android devices. Linux hosts support manual and automation sessions on Android devices, alongside existing Mac mini hosts.

* Install deviceConnect with a `.deb` package on Debian-based distributions, such as Ubuntu, or an `.rpm` package on Red Hat-based distributions, such as Fedora or Rocky Linux.
* Upgrades keep your existing deviceConnect configuration.
* Uninstall deviceConnect with your distribution's package manager.

iOS devices are not supported on Linux hosts. deviceConnect cannot be installed on the same Linux host as GigaCap.

For host requirements, see xref:device-lab-management:deviceConnect/hardware-requirements-for-deviceconnect.adoc[].
