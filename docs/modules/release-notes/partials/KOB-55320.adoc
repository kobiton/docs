== Run deviceConnect on Linux hosts for Android devices

deviceConnect can now run on a Linux host to connect Android devices to Kobiton. Previously, deviceConnect required a Mac mini host.

* deviceConnect is available as a `.deb` package for Debian-based distributions and an `.rpm` package for Red Hat-based distributions.
* The package bundles the runtime and Android tools that deviceConnect uses, and installs deviceConnect as system services.
* Configuration changes you make on the host are kept when you upgrade deviceConnect.
* Uninstall deviceConnect with your distribution's package manager.

Linux hosts support Android devices only. iOS devices continue to require a Mac mini host. deviceConnect and GigaCap cannot be installed on the same Linux host.

For hardware requirements, see xref:device-lab-management:deviceConnect/hardware-requirements-for-deviceconnect.adoc[].
