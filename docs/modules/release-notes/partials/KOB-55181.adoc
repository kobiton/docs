== virtualUSB

- On Windows, libimobiledevice and go-ios now work with iOS and iPadOS devices connected through virtualUSB 2. Previously, these tools listed connected device UDIDs, but commands that open a session with the device, such as `ideviceinfo` and `ios info`, failed with an SSL or pair record error. Running `idevicepair` did not resolve the failure.
