== Kobiton AI plugin

- The `listFlexCorrects` MCP tool returns the `flexCorrect` corrections recorded on an automation session. Each item reports the corrected element, the baseline device capabilities, and the matching test step.
- Results are paged. `limit` defaults to 10 and is capped at 20, `offset` starts at 0, and the response reports `total_items` and `total_pages` alongside the requested page. A session with no corrections returns an empty result rather than an error.
- The `GET /v2/validations/flex-correct` endpoint returns the same corrections as a paged list, using `sessionId`, an optional `commandId`, `page`, and `rowsPerPage`. `GET /v2/validations` is unchanged.
