== deviceConnect console: Kobiton and gigacap connection status

- Added a connection status strip to the deviceConnect console header, next to the user menu. A dot and label for *Kobiton* and *gigacap* show whether the host machine is connected to each service. Hover over a service to see its state and the reason for it.
- Each service shows one of these states: *Online*, *Offline*, *Error*, or *Not Configured*. *Kobiton* shows *Error* when the tenant credentials configured for the host are rejected, for example a wrong API key or a key that belongs to another account. A service shows *Not Configured* when the host is not set up to use it.
- The status updates automatically when a connection changes. A page reload is not required.
- While the console cannot reach deviceConnect, for example during a service restart, the dots turn gray. They return to the current state when deviceConnect is available again.
- In browser windows narrower than 1200 pixels, only the dots are shown.
