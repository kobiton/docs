== WEBVIEW discovery for later Appium sessions in Android mixed sessions

Fixed an issue where, in a mixed session on an Android device, only the first Appium session could find the `WEBVIEW` context for a web page open in Chrome or a Chrome Custom Tab, such as an Auth0 authentication page. Later Appium sessions in the same mixed session listed only `NATIVE_APP`, without an error.

Each Appium session in a mixed session now lists the `WEBVIEW` context and can switch to it. Mixed sessions that run a single Appium session work as before.
