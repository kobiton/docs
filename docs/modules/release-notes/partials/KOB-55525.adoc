=== Usage report

* Updated the xref:reporting:usage-report/use-the-report.adoc[usage report] to record session data, including session counts, minutes, and validation counts, when a session ends instead of on a periodic schedule.
* Validation results that finish after a session ends now update that session's counts in the usage report.

The report contents and how you view the report are unchanged.
