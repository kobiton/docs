=== Organization settings for Appium AI

Administrators can now configure Appium AI for the whole organization in Kobiton Portal. New Appium sessions use the organization's LLM provider and locator settings without requiring per-session configuration.

*Highlights*

* Turn Appium AI on or off for the organization.
* Set the default LLM endpoint, API key, API format, text and vision models, extra request body, locator strategy, and coordinate space.
* Require an API key whenever an LLM endpoint is set, except for the Ollama chat API format.
* Apply saved settings to new sessions on every device host in the organization. Running sessions keep their current settings.
* Override organization settings for a single session with `kobiton:*` desired capabilities.

For details, see xref:automation-testing:appium-ai/configure-appium-ai-org-settings.adoc[Configure Appium AI settings for your organization].
