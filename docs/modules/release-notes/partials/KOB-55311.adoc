== virtualUSB

- On macOS, virtualUSB now pairs unpaired iOS 17.4 and later devices with the Mac automatically when they connect. Paired devices are available in Xcode, including Xcode 27.
- While a device pairs, the *Connection Status* column displays *Pairing...*, then *Connected*. If pairing does not complete, it displays *Pairing failed*.
- The *Pairing* toggle is removed from the device list. To pair a device again, disconnect it, select *Clear Pairing Data*, and connect it again.
- Automatic pairing requires Xcode on the Mac.
