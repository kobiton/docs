- New: Xium sessions on Android devices now support the `waitForIdleTimeout` setting, which controls how long the session waits for the app screen to become idle before each UiAutomator element search. Set it to `0` with the `appium:waitForIdleTimeout` capability or the Appium Settings API to find elements in apps that redraw continuously, where `-android uiautomator` locators such as `new UiSelector().resourceId("...")` previously returned `no such element`. The default stays at 10 seconds, so sessions that do not set the value behave as before. The setting is ignored on iOS.
