== Control the UiAutomator idle wait in Xium sessions on Android

- Xium sessions on Android devices now support `waitForIdleTimeout`. Set it with the `appium:waitForIdleTimeout` capability, or change it during the session with the Appium Settings API.
- Set `waitForIdleTimeout` to `0` to skip the idle wait before each UiAutomator element search. This fixes `no such element` errors for `-android uiautomator` locators, such as `new UiSelector().resourceId("<resource-id>")`, in apps that redraw continuously and never become idle.
- The default remains `10000` milliseconds, so sessions that do not set `waitForIdleTimeout` are not affected. On iOS devices, the setting is ignored.

For details, see xref:automation-testing:capabilities/available-capabilities.adoc#_waitForIdleTimeout[`waitForIdleTimeout`].
