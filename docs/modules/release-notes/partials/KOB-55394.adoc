// Area: Appium automation
// Source: KOB-55394

- Xium now supports the Appium `mobile: setText` command on Android and iOS. Scripts that call `mobile: setText` set the text of the target element instead of failing with `Mobile command 'mobile: setText' is not implemented`. Typing, sending keys, and clearing a field keep their existing behavior.
