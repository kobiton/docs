=== Automation testing

* *Session details for running XCUITest sessions:* Fixed an issue where session details failed to load while an XCUITest native framework session was still running. During the run, `+GET /v1/sessions/{id}+` and `+GET /v2/sessions/{id}+` returned an HTTP 500 error. Both now return the session at every stage of the run, including before its test report and video are available. Finished sessions with a recorded video keep their video link.
