== Minimum supported iOS and iPadOS version is now 15

Kobiton now supports devices running iOS and iPadOS 15 and later. Devices running iOS or iPadOS 12, 13, or 14 are no longer supported.

- Devices running iOS or iPadOS 12, 13, or 14 are rejected when they connect to deviceConnect. In *Device Management*, these devices show as offline with the message `UnsupportedOSVersionError`, and they can't be launched.
- The deviceConnect console shows `Operating system version 15.0 or later required.` for these devices.
- To keep using a device on one of these versions, update it to iOS or iPadOS 15 or later.

For the full list of supported versions, see xref:supported-platforms:mobile-operating-systems-and-devices.adoc[Supported OS versions].
