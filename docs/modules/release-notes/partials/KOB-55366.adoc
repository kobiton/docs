== List installed apps on a device with the API

Two new API endpoints return the apps installed on a private device, including apps that were not installed from the App Repository.

- `GET /v2/devices/{deviceId}/installed-apps` and `GET /v2/devices/udid/{udid}/installed-apps` return every app on the device, including apps installed through mobile device management (MDM), apps installed manually, and system apps.
- Each app includes its bundle ID, name, version, and build version as reported by the device. On Android, app names are empty.
- Add `includeKobitonAppVersionId=true` to return the App Repository `app_version_id` for apps that match an app version in your App Repository.
- The `type` parameter accepts `user`, `system`, `all`, `filesharing`, `enabled`, and `disabled`. In this release, every app is returned regardless of `type`. The `type_applied` response field reports the filter that was applied.
- If the device is offline or does not respond, the endpoints return an error that describes the problem.
- `GET /v2/devices/{deviceId}/apps` is unchanged and continues to return only apps in your App Repository.
