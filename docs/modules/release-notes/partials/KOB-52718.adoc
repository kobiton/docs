== Kobiton CLI: Session Explorer for CLI sessions

- Added the `--capture` option to `kobiton session create`. List the session data to capture, such as `screenshots`, `view-trees`, `logs`, `metrics`, or `video`, and review it in Session Explorer. Capture is opt-in. CLI sessions created without `--capture` capture no session data and continue to open on Session Overview.
