== Fewer duplicate steps in Kobiton CLI session timelines

The Session Explorer timeline for Kobiton CLI sessions no longer shows an extra `POST /session` step for every `kobiton webdriver` call. The timeline now shows the session creation once, followed by one step for each call.

* Repeated session creation requests are hidden from the timeline but remain in the session's command data.
* A failed session creation request still appears as a step.
* The device logs for each call include the log lines since the previous call.
* CLI sessions recorded before this change display the same way.

Automation and mixed sessions are not affected.
