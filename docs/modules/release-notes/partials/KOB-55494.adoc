=== Session Overview

- Fixed an issue where *View Device Logs* showed a `Failed to download log content` error for sessions that captured no device logs, such as Kobiton CLI sessions created without `logs` in the capture list. For these sessions, *View Device Logs* is now disabled, and its tooltip says "No device logs were captured for this session". *Download all* is also disabled when the session captured no logs at all. Sessions with device logs are unchanged.
