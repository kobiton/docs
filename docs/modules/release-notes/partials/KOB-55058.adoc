== deviceConnect

- *deviceConnect* now requires the `License.Valid=true` setting in the `dc.ini` file on each host. The setting defaults to `false`.
** New installations: add `License.Valid=true` to `dc.ini`, then restart *deviceConnect*. If the setting is missing or set to `false`, *deviceConnect* does not initialize.
** Existing hosts: hosts that already have `License.Valid=true` in `dc.ini` continue to work after the update. No action is required.
