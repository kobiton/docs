=== Kobiton CLI

* *iOS simulators:* `kobiton file list`, `kobiton file push`, `kobiton file pull`, and `kobiton device ps` now work on iOS simulators. Previously, `file list`, `file pull`, and `device ps` failed with a server error, and `file push` reported success without writing the file. The CLI now refuses paths outside the app's container on simulators.
* *iOS devices and simulators:* `kobiton file push` now fails with a non-zero exit code when the target app is not installed or not accessible. Previously, the push printed `Pushed <n> bytes` and exited `0` even though no file was written.
