== Kobiton CLI

- Fixed an issue where `kobiton file list`, `kobiton file pull`, and `kobiton device ps` failed on iOS simulators, and `kobiton file push` reported success without writing the file. You can now transfer files to and from an app's container on an iOS simulator and list the simulator's running processes.
