== Check service status from the help widget

The help widget in Kobiton Portal now includes a *Kobiton Status Page* option, so you can check service status before contacting Support. The option appears after *Support* and opens https://status.kobiton.com/[status.kobiton.com^] in a new tab.

This option is available on Kobiton Public Cloud. Private Cloud and Standalone deployments are unchanged.
