== Report descriptions and Category filter in Analytics Reports

The Analytics Reports page shows what each report is for and lets you filter the list by category.

* A *Description* column replaces the *Last synced at* column in the reports list. Long descriptions are shortened. Hover over a shortened description to see the full text.
* Each report page shows the report description below *Last synced*.
* A *Category* filter next to *Search* narrows the list to the selected categories. Search text and selected categories apply together.
