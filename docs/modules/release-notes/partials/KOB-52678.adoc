== Device Management

- The `GET /v2/machines` API now returns each host machine's `max_parallel_tests` setting as an object with `mode` and `limit` fields. `mode` is `unlimited` or `custom`. For `custom`, `limit` is the configured limit. For `unlimited`, `limit` is `null`.
- The `PATCH /v2/machines` API accepts the same `mode` and `limit` fields to set a host machine to `unlimited` or to a `custom` limit between 1 and 999. A `custom` request with a missing, zero, or negative `limit` returns HTTP 400, and no settings are saved.
- Existing `PATCH /v2/machines` requests that send `limit` without `mode` continue to work. A `null` `limit` sets the host machine to unlimited.
