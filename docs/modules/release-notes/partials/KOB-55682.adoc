=== Inspector

* *Jetpack Compose screens on Android:* Fixed an issue where the *Inspector* XML hierarchy was missing content on Android 13 and later for Jetpack Compose screens that contain native Android views. The hierarchy showed only elements such as the status bar and the bottom navigation, and the rest of the screen appeared as empty `android.view.View` elements with no text or resource ID. These screens now show their full content in the hierarchy.
