== Appium automation

- Fixed an issue on iOS 26 where the buttons in an app's location permission alert, such as *Allow Once*, *Allow While Using App*, and *Don't Allow*, were sometimes missing from the page source during automation sessions. Scripts that tried to find these buttons could fail with a `no such element` error. Scripts can now find the buttons and tap them to accept or dismiss the alert.
