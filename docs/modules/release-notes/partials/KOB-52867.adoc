== Control the idle wait before taps and swipes in Xium sessions

In Xium sessions on Android and iOS devices with `kobiton:waitForIdle` set to `true`, the idle wait before each tap or swipe now lasts up to the session's `waitForIdleTimeout` value instead of a fixed 5 seconds.

* Set the value when the session starts with `appium:waitForIdleTimeout` or inside the `appium:settings` capability. If both are set, the `appium:settings` value is used.
* Change the value during the session with the Appium Settings API. Set it to `0` to skip the idle wait.
* The value is in milliseconds on both Android and iOS devices.
* When no value is set, the wait before each tap or swipe now lasts up to 10 seconds instead of 5 seconds.

Basic Appium 2 sessions are not affected.

For details, see xref:automation-testing:capabilities/available-capabilities.adoc#_waitForIdleTimeout[waitForIdleTimeout].
