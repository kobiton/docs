== Fixed device release in earlier virtualUSB versions

- Fixed an issue where virtualUSB versions earlier than 4.20.0 failed to release a connected device. Running `vusb disconnect --udid <device-udid>`, or stopping `vusb connect` with Ctrl+C, reported `Device access ticket is not found`, and the virtualUSB session kept running in Kobiton Portal until it was terminated there. These commands now end the virtualUSB session and release the device, whether it was connected from the CLI or the virtualUSB app. No virtualUSB update is required.
