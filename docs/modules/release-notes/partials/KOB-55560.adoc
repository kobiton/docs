== Kobiton API

- Fixed the session commands endpoints returning more commands than Session Explorer shows for Kobiton CLI sessions. `GET /v1/sessions/\{id}/commands`, the v2 session commands endpoint, and `GET /v1/sessions/\{id}/commandsCount` now return one session creation plus one command per `kobiton webdriver` call, matching the steps in Session Explorer. Previously, these endpoints also returned the repeated `POST /wd/hub/session` request that Kobiton CLI sends before each call. This change applies to CLI sessions recorded after this release. Sessions recorded earlier are unchanged.
