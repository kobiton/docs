== Kobiton CLI: Screenshots in Session Explorer

- Steps in CLI sessions that do not have their own screenshot now show the screenshot from the previous step, as automation sessions do. Previously, these steps showed "Screenshot Not Available". This applies in Session Explorer and in the session command APIs.
- The XML hierarchy in *Appium Inspector* follows the same rule. *Appium Inspector* never pairs a screenshot with the XML hierarchy from an earlier step.
