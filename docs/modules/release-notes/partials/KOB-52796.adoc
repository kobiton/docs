== Single Sign-On (SSO) sign-in

- Fixed an issue where Kobiton Portal showed the username and password sign-in page to users with *SSO Only* turned on when the organization did not enforce SSO for all users. After these users enter their email address or username, Kobiton Portal now directs them to sign in through SSO. The password field and *Forgot Password?* are not available to them.
