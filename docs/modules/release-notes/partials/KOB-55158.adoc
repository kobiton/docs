== Session validations in the Kobiton AI plugin

- The Kobiton AI plugin adds a `listAccessibilityValidations` MCP tool. Ask your AI assistant for a session's accessibility findings and it returns them one page at a time, with a screenshot link for each finding that has one.
- `limit` sets the number of findings per call. It defaults to 10 and is capped at 20. `offset` skips findings you already read. Every response reports `total_items`, so you can tell how many findings the session recorded.
- A session that recorded no accessibility findings returns an empty result instead of an error.
- Kobiton API v2 adds a matching paged endpoint, `GET /v2/validations/accessibility`. It takes `sessionId`, an optional `commandId`, `page`, and `rowsPerPage`, and returns the standard v2 list envelope. `GET /v2/validations` is unchanged.
