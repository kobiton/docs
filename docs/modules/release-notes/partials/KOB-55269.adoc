== Leaner screen reads in the Kobiton automate plugin

The `drive-automation-session` and `run-interactive-session` skills now give your AI assistant a filtered view of the screen's UI tree by default. The filtered view keeps only interactive and labeled elements, such as elements with an ID, accessibility label, or text, or elements that are clickable, along with their bounds. This reduces how much of the page source your AI assistant reads on each step of a session.

- Filtering now applies to native Android and iOS screens as well as webviews.
- The full page source and screenshot are still captured, and your AI assistant can read them when the filtered view isn't enough.

Requires Kobiton automate plugin version 1.15.0 or later.
