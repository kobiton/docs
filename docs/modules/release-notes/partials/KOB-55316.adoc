== Device passcode

- Fixed an issue where Kobiton did not set the device passcode on iOS 27 and iPadOS 27 devices in organizations that use passcode mode. Affected iPads entered an error state and were unavailable for sessions. Affected iPhones stayed available, but the device did not hold the passcode shown in the Portal. Kobiton now sets the passcode on iOS 27 and iPadOS 27 devices, and the passcode on the device matches the one shown in the Portal.
