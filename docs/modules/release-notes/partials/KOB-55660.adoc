== Accurate colors in Lightning mode on Android devices

Lightning mode now displays accurate colors on Android devices.

Previously, red and blue could appear swapped in the Lightning mode video on some Android devices. For example, blue icons appeared orange. Screenshots in Session Explorer were not affected.
