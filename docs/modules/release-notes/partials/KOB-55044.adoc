== deviceConnect support for Linux hosts with Android devices

deviceConnect now runs on Linux hosts for Android devices. Organizations that host dedicated Android devices can use a Linux x64 machine as the deviceConnect host instead of a Mac mini.

Linux hosts support Android devices only. iOS devices continue to require a Mac mini host.

For host requirements, see xref:device-lab-management:deviceConnect/hardware-requirements-for-deviceconnect.adoc[].
