== iOS device stability

- On some iOS 15 devices, reading the device screen could crash the on-device agent and force it to restart. This affected view trees captured during manual sessions, *Inspector* view tree reads, element searches, and network payload capture setup. Screen reads now complete without crashing the agent. Behavior on iOS 16 and later is unchanged.
