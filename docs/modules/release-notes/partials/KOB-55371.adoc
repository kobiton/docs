== virtualUSB 2 downloads

Portal downloads now deliver the official virtualUSB 2 installers from the Kobiton public download site, and add Linux installers.

- *virtualUSB for Mac* and *virtualUSB for Windows* now download the latest virtualUSB 2 installer. Downloading does not require an additional sign-in.
- New *virtualUSB for Linux (Debian-based)* and *virtualUSB for Linux (Red Hat-based)* entries appear at the end of the Downloads list.
- The Downloads list now stays within the screen on smaller windows and supports keyboard navigation.
- Standalone installations include the same virtualUSB 2 installers for all four platforms.
