== virtualUSB downloads

The virtualUSB entries in the Portal *Downloads* list now download the official virtualUSB 2 installers, and Linux installers are now available.

*Highlights*

- *virtualUSB for Mac* and *virtualUSB for Windows* download the latest virtualUSB 2 installer from Kobiton's public download site. No additional sign-in is required.
- New *virtualUSB for Linux (Debian-based)* and *virtualUSB for Linux (Red Hat-based)* entries appear at the end of the *Downloads* list.
- The *Downloads* list stays within the screen on smaller windows and supports keyboard navigation.
- Standalone installations include the same virtualUSB 2 installers for macOS, Windows, Debian-based Linux, and Red Hat-based Linux.
