== Kobiton MCP server

- New: the `automate` MCP plugin adds a `listElementSelectionValidations` tool that returns a session's element-selection validations one page at a time. Each validation covers a test step whose target element resolved to a different element than expected, and carries the test step version's screens, target element, action type, and action data.
- The tool takes a required `sessionId`. `limit` defaults to 10 and is clamped to 20, and `offset` defaults to 0 and maps to a 1-indexed page. A session with no element-selection validations returns `total_items: 0` and an empty `items` array rather than an error.
- New: `GET /v2/validations/element-selection` returns the same validations through the v2 list envelope, filtered by a required `sessionId` and an optional `commandId`. `GET /v2/validations` is unchanged.
