== Reporting

- New: the *Device Utilization* report shows device usage by sessions, testing minutes, and unique users for a date range you select. Organization admins open it from *Reports*, under the *Device* category.
- The report lists device name, custom device name, manufacturer, OS, version, UDID, team, and public or private device type alongside the usage counts, sorted so the most-used devices appear first.
- Filter the report by date range and by public or private devices, and narrow it to a team through the table search box.
