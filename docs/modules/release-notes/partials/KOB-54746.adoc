=== Accessibility

* *TalkBack Enhanced keymap:* Fixed an issue where the *Screen Reader* panel buttons, such as *Next* and *Previous*, did not move the TalkBack focus on Android devices that use the Enhanced keymap introduced in TalkBack 16.2. The buttons now work with both the Default and Enhanced keymaps. Switching the device back to the Default keymap is no longer required.
