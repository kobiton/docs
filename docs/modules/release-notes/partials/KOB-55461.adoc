== Turbo Test reports

- Completed Appium Turbo Test sessions now consistently show the *Test Report* section in Session Overview, and the session details in the Kobiton API include the test report download URL. Previously, a small number of completed sessions showed no test report, even though the report was generated.

For details on downloading test reports, see xref:automation-testing:turbo-test-execution/run-appium-test.adoc#_download_test_report[Download test report].
