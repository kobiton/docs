== Turbo Test Execution test reports

Fixed an issue where some Turbo Test Execution sessions completed successfully but did not show a *Test Report* in Kobiton Portal, and the session API did not return a test report download URL. Test reports for these sessions are now linked to the session when it starts and are available after the session completes.

For details on downloading test reports, see xref:automation-testing:turbo-test-execution/run-appium-test.adoc#_download_test_report[Download test report].
