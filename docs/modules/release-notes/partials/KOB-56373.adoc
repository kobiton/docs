== Reliable Power button unlock for passcode-enabled iOS devices in Lightning mode

In organizations that use passcode (PIN) mode, iOS manual sessions in Lightning mode now recover when you select *Power* twice. After the second *Power*, the device passcode is filled in automatically, the device unlocks, and the live view shows the device screen again.

Previously, the device could stay locked and the live view could stay black. Unlocking the device another way, such as selecting *Home* and entering the passcode, did not bring the live view back.

The live view stays dark between the first and second *Power* while the device screen is off.
