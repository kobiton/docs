=== Reports

- Access to the *Usage Report* and *Service Level Availability* reports is now determined by organization role. Users with the ADMIN role can view both reports. Users with the MEMBER role cannot view them, regardless of email domain.
- Viewing Service Level Availability data now requires the organization management permission.
- All other predefined reports remain visible to everyone in the organization.
