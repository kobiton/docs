== Bug fixes and improvements

=== Reporting

- Fixed an issue where predefined reports were not available after installing or upgrading to Kobiton Standalone 4.27.0S. Report setup now completes during installation and upgrade, and the reports are listed and render in the Portal.
- Fixed an issue where report dashboard setup did not complete on Standalone deployments that use a hostname, rather than an IP address, for the Portal URL.

_Applies to Kobiton Standalone deployments._
