== Device Management

- The *Settings* window on *Settings > Device Management* now lists the same host machines as the Device Management page. Searching the window by host machine name or by IP address returns the same host machines that a search on the page returns. Previously the window could also list host machines that the page did not show, including several rows carrying the same host machine name and the same IP address.

- Settings saved in the window now apply to a host machine shown on the page. Each of the extra rows held its own *Max Parallel Tests* value and virtualUSB setting, so a change could previously be saved against a row that matched no host machine visible on the page, with nothing on screen to indicate which row took effect.

- The *All Machines* row reports the combined state of the host machines listed in the window. Previously it read *Mixed* when the extra rows held different values.

- The change applies to both the *virtualUSB* tab and the *Max Parallel Tests* tab.

- A host machine appears in the *Settings* window only while at least one of its devices is visible on the Device Management page. A host machine whose devices are all hidden no longer appears in either place. Unhide one of its devices to configure the host machine again.
