=== Usage Dashboard replaces the Usage Report

The Usage Dashboard is now available to organization admins in the *Usage* category of Analytics Reports. It replaces the previous Usage Report.

* Filter by date range and, optionally, by team.
* Review totals for sessions, minutes, devices used, and active users.
* Review session counts by type and date, and usage statistics for each team.
* See top users and most-used devices ranked by testing minutes, with each user or device listed once and all of its teams shown in the *Team* column.
* Export the dashboard as a CSV file.
