== virtualUSB

- On Linux, `vusb status` reported `"version": "0.0.0-test"` instead of the version of the installed build. It now reports the installed build version, matching `vusb --version` and the installed `kobiton-vusb` package. Connecting to, serving, and disconnecting from devices were not affected.

[NOTE]
====
Upgrade `kobiton-vusb` to a build from this release or later to pick up the corrected version. Earlier Linux packages continue to report `0.0.0-test`.
====
