== Security updates for Standalone

- The Kobiton Portal, user guide, and help widget images for Standalone deployments now use nginx 1.30.7. This update addresses known security vulnerabilities in the web server and system packages of the previous images.
- The user guide and help widget move from the nginx 1.31.x mainline release to the 1.30.7 stable release, so security scanners may report a lower nginx version number for these images than before.
- Web server configuration and served content are unchanged.
