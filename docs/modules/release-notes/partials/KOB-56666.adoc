== deviceConnect

- Updated the nginx web server bundled with deviceConnect on macOS host machines to version 1.30.7. This version addresses security vulnerabilities published by the nginx project for version 1.30.4. The update is installed automatically when a host machine is upgraded to this deviceConnect release. No configuration changes are required, and existing nginx settings are preserved. Linux host machines aren't affected because they use the nginx package provided by the operating system.
