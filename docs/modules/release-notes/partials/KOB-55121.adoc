== Appium AI

- Appium AI now uses the LLM settings configured for your organization. Natural language finds use your organization's endpoint, models, and API key without host configuration changes or extra capabilities in test scripts. Session capabilities (`kobiton:llm*`) still take precedence, field by field. Organizations without LLM settings keep using the host defaults.
- Organization admins can turn off Appium AI for their organization. When Appium AI is off, natural language finds fail with the error `LLM client is disabled for this organization`, and session capabilities cannot turn it back on.
