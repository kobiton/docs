== Appium AI uses organization LLM settings

Appium AI now uses the LLM settings configured for your organization. Natural language locators use your organization's endpoint, models, and API key without host configuration changes or extra capabilities in test scripts.

* Session capabilities (`kobiton:llm*`) still take precedence over organization settings, one setting at a time.
* Organization admins can turn off Appium AI for their organization. When it is off, natural language finds fail with the error `LLM client is disabled for this organization`, and session capabilities cannot turn it back on.
* Organizations without LLM settings continue to use the host defaults.
* Changes to organization settings apply to the next new session. Running sessions keep their settings.

Appium AI is in Beta and is available on Private and Local devices only.

For details, see xref:automation-testing:appium-ai/configure-appium-ai-org-settings.adoc[Configure Appium AI settings for your organization] and xref:automation-testing:appium-ai/override-llm.adoc[Override Appium AI settings per session].
