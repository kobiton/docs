=== Kobiton MCP server

* `listTestCases`, `listTestSuites`, and `listTestRuns` now return at most 20 items per call. `rowsPerPage` defaults to 10 and is clamped to the range 1 to 20, and `total_items` still reports the full count so an assistant can page through larger result sets. This keeps an AI assistant from requesting a response too large for its context.
* `getUserInputEvents` now returns at most 20 events per call. `limit` defaults to 10, down from 50, and is clamped to the range 1 to 20.
* The four tool descriptions now state the default and maximum page size.

These limits apply to the MCP tools only. The REST API and Kobiton Portal are unchanged.
