== Session Explorer keeps steps after private mode ends

In Xium and Appium automation sessions that use `kobiton:privateMode`, Session Explorer now keeps the step that turns private mode off and every step after it. Previously, if a script ran commands while private mode was on, turned private mode off, and then ended the session within about 5 seconds, those steps were missing from Session Explorer.

Sessions that don't turn on private mode are unchanged.
