// Virtual Devices list shows the configured emulator name.
// Target section on the release page: == Portal
// Draft staged by Robot Ranch. Not yet included in a release page.

- The *Virtual Devices* tab in *Device List* now shows each Android emulator under its configured device name. Previously, every emulator on a host appeared under a shared model string such as `sdk_gphone64_arm64`, so you could not tell emulators on the same host apart.
- The *Search devices* box matches an emulator by its configured name.
- The *Device Model* column continues to show the emulator model string.
