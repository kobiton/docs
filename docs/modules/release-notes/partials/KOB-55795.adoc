=== Device logs for terminated sessions

Device logs are now available for sessions that end without a normal close, such as terminated sessions.

* Device logs and device metrics for other sessions are unchanged and are available shortly after the session ends.
* Device log entries and metrics that arrive long after a session ends are no longer added to that session.
