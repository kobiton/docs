* *Virtual device badge:* Sessions on iOS simulators and Android emulators now show a *Virtual Device* badge in the session header, so you can tell a virtual session from a real-device session without opening *More info* or the *Overview* tab.
** In a manual session, the badge appears after the OS version, before *More info*.
** In Session Explorer, the badge appears after the OS version on the *Explorer* and *Overview* tabs, including for virtual-device sessions recorded before this release.
+
Sessions on real devices do not show the badge. For details, see xref:manual-testing:start-a-virtual-session.adoc#_identify_a_virtual_session[Identify a virtual session].
