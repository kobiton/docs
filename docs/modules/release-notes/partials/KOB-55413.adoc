== Apps install on iOS Simulators at the start of Appium sessions

When an Appium session on an iOS Simulator installs an app at session start with the `appium:app` capability, the app now installs without an app re-signing check. Simulator builds don't need re-signing. Previously, the session could fail before the app was installed, with an error stating that app signing is temporarily unavailable for the device.

Real iOS devices and Android devices keep the existing app re-signing behavior.
