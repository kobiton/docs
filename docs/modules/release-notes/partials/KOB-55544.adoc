== Install `.app` builds on real iOS devices in manual sessions

In manual sessions, the *Install Apps* modal now accepts `.app` builds on real iOS devices and stops installs of iOS builds that can't run on the device in use.

* *Upload File* and *Install From URL* accept a zipped `.app` on real iPhones and iPads. A device build `.app` installs the same way as an `.ipa`.
* A Simulator build on a real iOS device is rejected with a clear message before install, instead of failing during install.
* A device build on an iOS Simulator is rejected with a clear message before install.
* Android sessions and iOS builds that match the device work as before.

For details, see xref:manual-testing:install-an-app.adoc#_install_ios_app_builds[Install `.app` builds on iOS].
