== AI plugin and MCP tools

- The `automate` plugin adds the `getAccessibilityValidationsSummary` MCP tool. Pass a session ID to get counts of that session's accessibility issues, broken down by issue type and by issue name, together with the number of commands scanned and the time of the most recent validation.
- The summary returns counts only, so an AI assistant can size a session's accessibility results before retrieving the issues themselves. A single session can hold tens of thousands of issues.
- A session with no accessibility issues returns a total of `0` with empty breakdowns rather than an error.
