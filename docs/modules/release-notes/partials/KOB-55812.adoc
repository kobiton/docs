== Manual sessions on iPhone Duo devices and simulators

Manual sessions on iPhone Duo devices and iPhone Duo simulators now show the screen in use and respond to input on both the cover screen and the inner screen. Previously, the session stream was black while the device was folded, and taps missed their targets while it was unfolded.

* The session stream, taps, and screenshots follow the screen in use, folded or unfolded.
* Select *Fold device* or *Unfold device* on the session toolbar to change the posture. The control appears only on foldable devices.
* *Inspector* highlights and element taps in apps line up with the screen in use.
* On a real iPhone Duo, *Rotate Screen* is disabled. On iPhone Duo simulators, *Rotate Screen* rotates the screen in use.

For details and limitations, see xref:manual-testing:foldable-devices.adoc#_iphone_duo[iPhone Duo].
