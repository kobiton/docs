== Lightning Mode fix for some Android devices

- Fixed an issue where Lightning Mode failed to start on some Android devices, such as the Samsung Galaxy Tab A9+, whose video encoder does not support the device's full screen resolution. On these devices, Lightning Mode now streams at a lower resolution than the device's screen. Other devices continue to stream at the same resolution as before.
