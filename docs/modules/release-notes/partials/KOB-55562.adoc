== Turbo Test

=== More reliable session starts after executor reconnects

Turbo Test sessions now start reliably when test executors reconnect at the same time, such as after a network interruption or an executor restart.

- New sessions go only to executors that are online.
- Executors that stop responding are removed within about 15 seconds and no longer receive new sessions.
- If an executor's connection drops while a session is starting, the session fails quickly with an `Executor connection lost` error instead of waiting for a timeout.
