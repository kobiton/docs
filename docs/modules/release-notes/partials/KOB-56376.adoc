== Power unlocks passcode devices in the deviceConnect Console viewer

In organizations with passcode mode enabled, *Power* in the deviceConnect Console device viewer now unlocks a locked device the same way *Power* does in a Portal manual session. The lock screen appears, the device passcode is filled in automatically, and the device opens on the Home screen.

* Applies to Android, iOS, and iPadOS devices that use the organization passcode.
* In organizations without passcode mode, *Power* turns the device screen off and on, and no passcode is entered.
* *Power* in Portal manual sessions is unchanged.
