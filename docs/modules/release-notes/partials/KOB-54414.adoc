== Per-request logging for MCP 2026-07-28 clients

For AI clients that use version 2026-07-28 of the Model Context Protocol (MCP), log messages from the Kobiton MCP server are now controlled per request.

- Log messages are sent only for requests that set a log level in the `io.modelcontextprotocol/logLevel` field of `_meta`. Requests without this field receive no log messages.
- The `ping` and `logging/setLevel` requests and the `notifications/roots/list_changed` notification are no longer supported for these clients.
- Clients that use earlier MCP versions are not affected.
