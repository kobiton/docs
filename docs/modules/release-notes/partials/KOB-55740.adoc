== Passcode indicator for Android and HarmonyOS devices

The device list passcode indicator now covers Android and HarmonyOS devices, and the *Passcode* filter uses clearer labels.

- Android and HarmonyOS devices with a passcode now display the passcode icon in card view and list view, the same as iOS devices.
- The passcode icon tooltip now reads *Passcode enabled*.
- The *Passcode* filter in the device search bar now offers *Enabled* and *Not Enabled*, replacing *Supported* and *Not Supported*. *Enabled* returns devices with a passcode on every platform.

For details, see xref:devices:device-metadata.adoc#_passcode[Passcode].
