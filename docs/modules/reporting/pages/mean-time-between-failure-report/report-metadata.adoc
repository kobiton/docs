= Metadata for the mean time between failure report
:navtitle: Report metadata

The mean time between failure (MTBF) report is a predefined report measuring the average time, in hours, that devices remain online and available between offline events. For more information, see xref:reporting:mean-time-between-failure-report/use-the-report.adoc[].

== Data included

The report covers device offline events recorded within the selected date range, summarized by week.

An offline event counts as a failure. MTBF for a week is the average number of hours devices stayed online and available between offline events in that week.

== Values

=== Failures

The number of device offline events recorded in the period.

=== MTBF

The average time, in hours, that devices remained online and available between offline events in the period. Higher values indicate greater device stability and reliability.

When a period has no offline events, MTBF shows as 1000 hours. This value is a placeholder, not a measurement.
