= Use the mean time between failure report
:navtitle: Use the report

The mean time between failure (MTBF) report shows how long devices remain online and available between offline events. For more information, see xref:reporting:mean-time-between-failure-report/report-metadata.adoc[].

== Availability

The MTBF report is available to organization admins in every organization.

== Open the report

In Portal, select the *Analytics Reports* icon, then select *Mean Time Between Failure*.

== Read the results

The report charts MTBF over time, summarized by week. Each point shows the average number of hours devices stayed online and available between offline events during that week.

Higher MTBF values indicate greater device stability and reliability. A falling trend indicates devices are going offline more often.

A week with no offline events shows an MTBF of 1,000 hours. This value is a placeholder used when there are no offline events to measure against, not a measured result.
