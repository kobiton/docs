== Open the report

In Kobiton, select *Reports*.

Under *Device*, select *Mean Time Between Failure*.

== Filter the report

=== By date range

Select a date range. The report shows MTBF values for the periods within that range.

== Read the results

The report charts MTBF over time, summarized by week. Each point shows the average number of hours devices stayed online and available between offline events during that week.

Higher MTBF values indicate greater device stability and reliability. A falling trend indicates devices are going offline more often.

A week with no offline events shows an MTBF of 1000 hours. This value is a placeholder used when there are no offline events to measure against, not a measured result.
