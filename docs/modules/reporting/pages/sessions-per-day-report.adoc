= Sessions per Day report

Review the number of sessions run per day over a selected date range.

== Availability

The Sessions per Day report is available to organization ADMINs.

== Open the report

Select *Analytics Reports*, then *Sessions per Day*.

== Use the report

Select a date range to review sessions during that period.

To export the report, select *Export > Export report*, then download it as CSV or PNG. Select *Bookmark* to save the report for later.

The *Last synced* indicator shows when the report data was last refreshed.

== Understand the report

The report renders as a bar chart with one bar per day. Hover over a bar to see the number of sessions run that day.
