= Use the device utilization report
:navtitle: Use the report

View device usage by sessions, testing minutes, and unique users for a selected date range. For more information, see xref:reporting:device-utilization-report/report-metadata.adoc[].

== Availability

The device utilization report is available to organization admins in every organization.

== Open the report

In Kobiton, select *Reports*.

Under *Device*, select *Device Utilization*.

== Filter the report

=== By date range

Select a date range. The report shows device usage recorded within that range.

=== By team

Enter a team name in the search box. The search box matches text in the columns shown in the table, including the *Team* column.

=== By public or private devices

Use the *Public/Private* filter to limit the report to one device type. The *Public/Private* column shows the device type for each row.

== Read the results

Rows are sorted by *Sessions* in descending order, so the most-used devices appear first.
