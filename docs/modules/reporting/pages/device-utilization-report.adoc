= Device utilization report

The device utilization report measures device usage by sessions, testing minutes, and unique users for a selected date range.

== Availability

The device utilization report is available to organization admins in every organization.

== Open the report

Select *Analytics Reports*, then *Device Utilization*.

== Filter by date range

Select a date range. The report shows device usage recorded within that range.

== Read the results

Rows are sorted by *Sessions* in descending order, so the most-used devices appear first.

== Export the report

Select *Export*, then *Export report*. Choose *Download as CSV* or *Download as PNG*.

== Bookmark the report

Select *Bookmark* to save the report for quick access later.

== Data included

The report covers device usage recorded within the selected date range. Sessions run by users with a `kobiton.com` email address are excluded, so an organization whose only activity comes from those accounts shows no data.

== Report fields

=== Device Name

The name of the device.

=== Custom Device Name

The custom name assigned to the device by your organization.

=== Manufacturer

The device manufacturer.

=== OS

The device operating system.

=== Version

The device operating system version.

=== UDID

The unique device identifier.

=== Pool

Whether the device is public or private.

=== Team

The team the recorded usage belongs to.

=== Sessions

The number of test sessions run on the device within the selected date range.

=== Minutes

The number of testing minutes recorded on the device within the selected date range.

=== Unique Users

The number of distinct users who ran a session on the device within the selected date range.
