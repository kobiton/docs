= Device Utilization report

Review device usage by sessions, testing minutes, and unique users over a selected date range.

== Availability

The Device Utilization report is available to organization ADMINs.

== Open the report

Select *Analytics Reports*, then *Device Utilization*.

== Use the report

Select a date range to review device usage during that period.

To export the report, select *Export > Export report*, then download it as CSV or PNG. Select *Bookmark* to save the report for later.

== Understand the report

Each row shows a device's usage during the selected date range: sessions, testing minutes, and unique users. Rows are sorted by *Sessions* in descending order, so the most-used devices appear first.

The *Pool* column indicates whether the device is Public or Private.

Sessions run by users with a `kobiton.com` email address are excluded, so an organization whose only activity comes from those accounts shows no data.
