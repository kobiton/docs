= Mean Time Between Failure report

Review how long devices remain online and available between offline events. The report charts MTBF by week over time.

== Availability

The Mean Time Between Failure report is available to organization ADMINs.

== Open the report

Select *Analytics Reports*, then *Mean Time Between Failure*.

== Use the report

Select a date range to review MTBF during that period.

To export the report, select *Export > Export report*, then download it as CSV or PNG. Select *Bookmark* to save the report for later.

== Understand the report

The report charts MTBF over time, summarized by week. Each point shows the average number of hours devices stayed online and available between offline events during that week.

Higher MTBF values indicate greater device stability and reliability. A falling trend indicates devices are going offline more often.

A week with no offline events shows an MTBF of 1,000 hours as a placeholder, not a measurement.
