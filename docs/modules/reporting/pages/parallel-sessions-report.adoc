= Parallel Sessions report

Review peak parallel sessions per day over a selected date range.

== Availability

The Parallel Sessions report is available to organization ADMINs.

== Open the report

Select *Analytics Reports*, then *Parallel Sessions*.

== Use the report

Select a date range to review peak parallel sessions during that period.

To export the report, select *Export > Export report*, then download it as CSV or PNG. Select *Bookmark* to save the report for later.

The *Last synced* indicator shows when the report data was last refreshed.

== Understand the report

The report renders as a bar chart with one bar per day. Hover over a bar to see the peak parallel sessions count for that day.

*Peak Parallel Sessions* is the highest number of parallel sessions recorded on a given day in the selected date range. The count includes devices in active sessions and retained devices without active sessions. A device that is both retained and in an active session is counted only once.
