= Parallel Sessions report

The Parallel Sessions report shows the peak number of parallel sessions per day across a selected date range.

== Availability

The Parallel Sessions report is available to organization admins in every organization.

== Open the report

Select *Analytics Reports*, then *Parallel Sessions*.

== Filter by date range

Select a date range. The report shows the peak parallel sessions recorded on each day in that range.

== Read the results

The report renders as a bar chart with one bar per day. Hover over a bar to see the peak parallel sessions count for that day.

A *Last synced* indicator under the report title shows when the data was last refreshed from Portal.

== Export the report

Select *Export*, then *Export report*. Choose *Download as CSV* or *Download as PNG*.

== Bookmark the report

Select *Bookmark* to save the report for quick access later.

== Data included

Peak parallel sessions include devices in active sessions and retained devices without active sessions. A device that is both retained and in an active session is counted only once.

== Report fields

=== Peak Parallel Sessions

The highest number of parallel sessions recorded on a given day in the selected date range.
