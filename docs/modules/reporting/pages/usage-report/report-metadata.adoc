= Metadata for the usage report
:navtitle: Report metadata

The usage report measures component usage across all user test sessions. For more information, see xref:reporting:usage-report/use-the-report.adoc[].

image:reporting:columns-usage-report-context.png[width=1000,alt="Columns in Usage report"]

== Report fields

=== Components

The type of component being measured for usage. For more information, see xref:_component_types[].

=== Quantity

The volume recorded for the component. The unit varies by component: sessions, downloads, corrections, or issues and the screens they were found on.

=== Minutes

The number of minutes this component was used across all sessions. Only session-based components report minutes.

[#_component_types]
== Component types

Components appear in the report in the order below.

=== Manual

xref:manual-testing:index.adoc[Manual test sessions].

=== Automation

xref:automation-testing:index.adoc[Automation test sessions].

=== Mixed

xref:manual-testing:start-a-mixed-session.adoc[Mixed test sessions].

=== Test Case

xref:test-management:test-cases.adoc[Test Cases].

=== Test Suite

xref:test-management:test-suites.adoc[Test Suites].

=== Test Run

xref:test-management:test-runs.adoc[Test Runs].

=== Revisit Execution

Revisit sessions executed as part of a xref:test-management:test-runs.adoc[Test Run].

=== FlexCorrect

xref:automation-testing:capabilities/add-flexcorrect.adoc[flexCorrect] corrections applied during an automation session.

=== Crash Validation

Crash findings detected by the xref:test-management:test-runs.adoc#_automatic_validations[automatic validations] that run during a Test Run.

=== Accessibility Validation

xref:session-explorer:validations/validate-accessibility.adoc[Accessibility validation] issues and the screens they were found on. The next three components break this total down by issue type.

=== Touch Target Size

xref:session-explorer:validations/validate-accessibility.adoc#_touch_target_size[Touch target size] issues.

=== Color Contrast

xref:session-explorer:validations/validate-accessibility.adoc#_color_contrast[Color contrast] issues.

=== Content Labeling

xref:session-explorer:validations/validate-accessibility.adoc#_content_labeling[Content labeling] issues.

=== Response Time Validation

xref:session-explorer:analytics/review-network-payload-data.adoc#_review_response_times[Response time] findings and the screens they were found on.

=== Export Appium Script

Appium scripts exported from a Test Case. For more information, see xref:test-management:generate-appium.adoc[]. The next four components break this total down by xref:test-management:generate-appium.adoc#_supported_languages_and_frameworks[language and framework].

=== Java TestNG

Scripts exported as Java with the TestNG framework.

=== Java JUnit

Scripts exported as Java with the JUnit framework.

=== Node.js Mocha

Scripts exported as Node.js with the Mocha framework.

=== C# NUnit

Scripts exported as C# with the NUnit framework.
