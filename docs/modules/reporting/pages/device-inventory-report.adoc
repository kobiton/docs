= Device Inventory report

Review every device in your organization's lab, including hardware details, status, and team assignment.

== Availability

The Device Inventory report is available to organization ADMINs.

== Open the report

Select *Analytics Reports*, then *Device Inventory*.

== Use the report

*Status*, *Is assigned to team?*, *UDID*, *OS*, and *Manufacturer* filters appear by default. Select *More filters* to add *Version*, *Device Model*, and *Device Name*.

Select one or more values in each filter dropdown, then select *Apply* to filter the results.

To search within the filtered results, enter text in the *Search* box above the table.

To export the report, select *Export > Export report*, then download it as CSV or PNG. Select *Bookmark* to save the report for later.

The *Last synced* indicator shows when the report data was last refreshed.

== Understand the report

Each row shows a device in the inventory with its hardware details, operating system, status, and team assignment.

The *Status* column uses the values *ACTIVATED*, *UNPLUGGED*, and *UTILIZING*.

The *Device Name* column shows the manufacturer-defined name, such as *Galaxy S22*, unless you have set a custom name for the device.

The *Assigned Team* column shows *Not assigned* for unassigned devices, or a semicolon-separated list of team names for assigned devices.
