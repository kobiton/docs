== Find reports

The Analytics Reports page lists the available reports. The *Description* column shows what each report is for. Long descriptions are shortened. Hover over a shortened description to see the full text.

To narrow the list, use either or both of the following:

* *Search:* Enter text in the *Search* box.
* *Category:* Next to the *Search* box, select the categories to show. All categories are selected by default, and only categories of the reports available to you are listed.

When both are used, the list shows only reports that match the search text and belong to a selected category. If no categories are selected, no reports are shown.

Reports without a category are listed under *Uncategorized*.

On a report page, the report description appears below *Last synced*.

== Bookmark reports

Bookmark a report to keep it at the top of the Reports list on the Analytics Reports page.

You can bookmark a report from either location:

* **Within a report:** Select the bookmark icon.
* **On the Analytics Reports page:** In the *Actions* column, select the bookmark icon for the report.

== Export reports

Select *Export*, choose *Download as CSV* or *Download as PNG*, then select *Download*.
