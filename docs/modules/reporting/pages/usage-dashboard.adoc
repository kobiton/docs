= Usage Dashboard
// Source: KOB-55633

Analyze session activity over a selected date range, including total sessions, testing minutes, top users, most-used devices, and usage by team.

== Availability

The Usage Dashboard is available to organization admins. It appears in the *Usage* category of Analytics Reports.

== Open the dashboard

Select *Analytics Reports*, then *Usage Dashboard*.

== Filter the dashboard

Use the following filters:

* *Begin Date* and *End Date*: set the date range for all sections.
* *Team*: optionally limit the results to one team.

== Understand the dashboard

The dashboard contains the following sections:

* *Sessions*, *Minutes*, *Devices Used*, and *Active Users*: totals for the selected date range.
* *Session Count By Type and Date*: session counts across the selected date range, grouped by session type.
* *Team Statistics*: usage totals for each team.
* *Top Users*: users ranked by testing minutes, highest first. The *Team* column lists every team the user was active in during the date range.
* *Most Used Devices*: devices ranked by testing minutes, highest first. The *Team* column lists every team that used the device during the date range.

Each user and each device appears in one row, even when they were active in more than one team.

== Export the dashboard

Select *Export*, choose *Download as CSV* or *Download as PNG*, then select *Download*.

The CSV file contains all dashboard sections in a single sheet.

In PNG exports, the *UDID* column in *Most Used Devices* can overlap the *Serial Number* column. Use the CSV export to view all columns.
