= Individual Sessions report

View all sessions started within the selected date range, with one row per session.

== Availability

The Individual Sessions report is available to organization ADMINs.

== Open the report

Select *Analytics Reports*, then *Individual Sessions*. The report is listed in the *Usage* category.

== Filter the report

The report shows sessions from the last 7 days by default.

* *Date Range*: Select the period to review. Only sessions started within this range appear.
* *Team*: Show sessions for one or more teams.
* *User Email*: Select one or more user emails. Enter part of an address to search the full user list.

After you change a filter, select *Apply* to update the report.

Filters combine. For example, select a date range, then a user email, to review one person's sessions for that period.

== Report columns

Each row represents one session and includes the following columns, in this order:

. *Session ID*
. *Session Start*
. *Session End*
. *User Email*
. *Team*
. *Device Name*
. *OS*
. *OS Version*
. *UDID*
. *Device Type*
. *Device Model*
. *Serial Number*
. *IMEI*
. *Phone Number*
. *Session Minutes*
. *Session Type*
. *Session State*
. *Session Deleted*
. *Session Deleted At*

== Export the report

Select *Export*, choose *Download as CSV* or *Download as PNG*, then select *Download*.

== Large result sets

The table displays up to 100,000 rows. Because the report lists every session, wide date ranges for large organizations can reach this limit and take longer to load.

When results reach this limit, narrow the *Date Range*, filter by *Team* or *User Email*, or export the report to CSV.
