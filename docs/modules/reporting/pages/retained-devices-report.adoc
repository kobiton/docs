= Retained Devices report

Review currently retained devices, including who retained each one, when the retention started and ends, and recent session activity.

== Availability

The Retained Devices report is available to organization ADMINs.

== Open the report

Select *Analytics Reports*, then *Retained Devices*.

== Use the report

To filter the report, type in the *Retained by email* or *UDID* dropdown and select one or more values. Select *Apply*.

To search within the filtered results, enter text in the *Search* box above the table.

To export the report, select *Export > Export report*, then download it as CSV or PNG. Select *Bookmark* to save the report for later.

The *Last synced* indicator shows when the report data was last refreshed.

== Understand the report

Each row shows a currently retained device: the device model and OS, who retained it, which teams or groups the retaining user belongs to, when the retention started and ends, and the device's most recent session activity.

When no devices are currently retained, the table has no entries.
