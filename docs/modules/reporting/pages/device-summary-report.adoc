= Device Summary report

Review current device counts by OS version. Separate tabs display the results for Android and iOS devices.

== Availability

The Device Summary report is available to organization ADMINs.

== Open the report

Select *Analytics Reports*, then *Device Summary*.

== Use the report

To filter by team, select a team from the *Team* dropdown.

To filter by tag, select a tag from the *Tag* dropdown.

To export the report, select *Export > Export report*, then download it as CSV or PNG. Select *Bookmark* to save the report for later.

== Understand the report

The *Android* and *iOS* tabs each display a *Device Summary by OS Version* table.

Rows group devices by OS version range rather than by individual version — for example, *5 or below* or *8.x*. Each row shows the counts of Available, Online, Utilizing, and Offline devices for that range.
