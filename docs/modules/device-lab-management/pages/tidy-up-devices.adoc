= Tidy up devices

Tidy up hides offline or unplugged physical devices and offline emulators from the device list in Device Management. Hidden devices automatically reappear when they reconnect.

Tidy up is available for both private and public devices.

== Hide offline devices

. In Kobiton Portal, select *Profile*, then *Settings*.
. Select *Device Management*.
. Select *Tidy up*.
+
The *Remove unused devices* window lists offline devices, including emulators. All devices are selected by default.
+
image::devices:tidy-up-remove-unused-devices.png[width=700,alt="The Remove unused devices window in Device Management"]
+
Each device displays its name, OS version, UDID, host machine IP address, state, and number of days offline.
+
* Devices offline for less than one day display `<1` in the *Days offline* column.
* A `-` indicates that the device was offline before the Tidy up feature was introduced.
+
Review the selected devices before continuing, particularly those that have been offline for a short time.

. Clear the checkbox next to *Name* to deselect all devices, then select the devices to hide. Use the search bar to find specific devices.
. Select *Confirm*.

The selected devices are hidden from the device list. They reappear when they reconnect.
