== Manage your credentials

[#_get_server_url]
=== Get the Appium server URL

The Appium server URL is used for Appium automation testing. Select the *Copy* icon to add it to your clipboard.

[#_get_an_api_key]
=== Get an API key

A default API key is automatically generated when you create an account. Select the *Copy* icon to add a key to your clipboard. You can copy the key whether it is hidden or visible.

[#_show_or_hide_an_api_key]
=== Show or hide an API key

API keys are hidden each time you open the API Keys page. Select the eye icon next to a key to show its value, then select the icon again to hide it.

Each key has its own control, so showing one key leaves the rest hidden. A key stays visible until you hide it or leave the page. Every key returns to the hidden state when you open the page again.

=== Create a new API key

To create a new API key, select *Generate New API Key*.

=== Rename an API key

To rename an API key, select the key's current name, then enter a new one.
