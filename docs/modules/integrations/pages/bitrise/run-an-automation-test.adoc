= Run an automation test using Bitrise
:navtitle: Run an automation test
// Source: KOB-33032, KOB-33033

Use the *Execute Automation Test on Kobiton* Bitrise step to run an Appium test script stored in a Git repository against a device in Kobiton Portal. The step clones the repository, installs dependencies, and runs the test commands synchronously, then returns the Kobiton job ID and report URL.

== Requirements

* A Bitrise project you can edit.
* A Git repository that contains your Appium test script. See xref:integrations:upload-a-project-to-your-cloud-vcs.adoc[Upload a project to your cloud VCS].
* A Kobiton account and API key. See xref:profile:manage-your-api-credentials.adoc[Manage your API credentials].
* A Kobiton account used by Kobiton Automation Test Executor. For CI pipelines, use a xref:integrations:create-a-shared-kobiton-account-for-automation-tests.adoc[shared Kobiton account] rather than a personal account.

== Add the step to your workflow

Add the step through Bitrise's workflow editor. The clone-and-run instructions in the step's source repository are for contributors who want to modify the step.

. In Bitrise, open the project and open its workflow editor.
. Open the workflow you want to add the test to, and select the position where the test should run.
. Add a step and search for *Execute Automation Test on Kobiton*.
. Select the step to add it to the workflow.

== Configure the step inputs

Set the following inputs on the step.

=== Kobiton authentication

[cols="1,3"]
|===
|Input |Description

|*Kobiton Username*
|Your Kobiton username.

|*Kobiton API Key*
|Your Kobiton API key. Treat this as a secret.
|===

=== Kobiton Automation Test Executor

[cols="1,3"]
|===
|Input |Description

|*Executor Server URL*
|Kobiton Automation Test Executor URL. For production, use `https://executor.kobiton.com`.

|*Kobiton Executor Username*
|Username of the xref:integrations:create-a-shared-kobiton-account-for-automation-tests.adoc[shared Kobiton account] used by Kobiton Automation Test Executor.

|*Kobiton Executor Password*
|Password for that account. Treat this as a secret.
|===

=== Test source

[cols="1,3"]
|===
|Input |Description

|*Git repository URL*
|URL of the Git repository that contains your test script.

|*Git repository branch*
|The branch to check out and run.

|*Git repository SSH key*
|SSH private key with access to the repository. Required when the repository is private. Treat this as a secret.

|*Root directory*
|Path inside the repository where the commands run. Defaults to `/`.

|*Commands*
|Shell commands that install dependencies and run the test. Defaults to `mvn test`.
|===

=== App under test

[cols="1,3"]
|===
|Input |Description

|*App*
|The application path or URL used by your test script to install the app under test.
|===

=== Target a specific device

By default, the step uses the device configuration in your test script. To override it from the step, enable *Use Custom Device* and set the device fields. Each value is passed to your script through the listed environment variable.

[cols="1,3"]
|===
|Input |Description

|*Use Custom Device*
|`true` to override the device configuration from the step. `false` to use the configuration in your script.

|*Kobiton Cloud Device Name*
|Device name. Passed to your script as `KOBITON_DEVICE_NAME`.

|*Device platform version*
|Platform version. Passed to your script as `KOBITON_SESSION_PLATFORM_VERSION`.

|*Device platform*
|`android` or `ios`. Passed to your script as `KOBITON_DEVICE_PLATFORM_NAME`.
|===

=== Scriptless Automation on a device bundle

Instead of running your test script, the step can trigger xref:scriptless-automation:index.adoc[Scriptless Automation] on a xref:organization:device-bundles/create-a-device-bundle.adoc[device bundle]. For the Scriptless workflow itself, see xref:scriptless-automation:run-scriptless.adoc[Run a Scriptless test].

[cols="1,3"]
|===
|Input |Description

|*Trigger Scriptless on multiple devices*
|`true` to run Scriptless Automation on the specified device bundle. `false` to run your test script instead.

|*Kobiton Device Bundle*
|ID of the device bundle to run on. Required when Scriptless is enabled.

|*Kobiton Scriptless Timeout*
|Maximum execution time in seconds.
|===

=== Execution

[cols="1,3"]
|===
|Input |Description

|*Wait for execution*
|`true` to block the step until the test finishes and print the console log and result. `false` to return as soon as the test is queued. Defaults to `true`.

|*Log type*
|`combined` for chronological output and error logs, `output` for output only, or `error` for error only. Defaults to `combined`.
|===

== Outputs

After the step runs, the following outputs are available to later steps in the workflow.

[cols="1,3"]
|===
|Output |Description

|`JOB_ID`
|Kobiton Automation Test Executor job ID for this run.

|`REPORT_URL`
|URL of the TestNG report for this run.

|`SCRIPTLESS_AUTOMATION_PASSED`
|Set when Scriptless Automation ran. Indicates whether the Scriptless run passed.
|===
