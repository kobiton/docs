= Upload an app to Kobiton App Repository using Bitrise
:navtitle: Upload an app
// Source: KOB-33032, KOB-33033

Use the *Upload application to Kobiton* Bitrise step to send an app binary produced by your Bitrise workflow to Kobiton App Repository. The step uploads the `.apk` or `.ipa` file at the path you specify. It does not build the app, and it is separate from Bitrise's own app onboarding.

== Requirements

* A Bitrise project connected to the source repository that builds your app.
* A workflow in that project that produces an `.apk` or `.ipa` file before the upload step runs.
* A Kobiton account and API key. See xref:profile:manage-your-api-credentials.adoc[Manage your API credentials].

== Add the step to your workflow

Add the step through Bitrise's workflow editor. The clone-and-run instructions in the step's source repository are for contributors who want to modify the step.

. In Bitrise, open the project and open its workflow editor.
. Open the workflow you want to add the upload to, and select the position where the upload should run. Place it after the step that produces the `.apk` or `.ipa` file.
. Add a step and search for *Upload application to Kobiton*.
. Select the step to add it to the workflow.

== Configure the step inputs

Set the following inputs on the step.

[cols="1,3"]
|===
|Input |Description

|*App Name*
|Title for the app in Kobiton. Defaults to `$BITRISE_APP_TITLE`.

|*App Path*
|Path to the `.apk` or `.ipa` file produced by an earlier step. Defaults to `$BITRISE_SIGNED_APK_PATH`.

|*App ID*
|App ID of an existing app in Kobiton App Repository. Set this to upload a new version of that app. Leave blank to create a new app entry.

|*App Type*
|`apk` for Android or `ipa` for iOS.

|*App Privacy*
|`public` to make the app available to your organization, or `private` to restrict it to you. Defaults to `public`.

|*Kobiton Username*
|Your Kobiton username.

|*Kobiton API Key/Secret*
|Your Kobiton API key. Treat this as a secret.
|===

== Outputs

After the step runs, the following outputs are available to later steps in the workflow.

[cols="1,3"]
|===
|Output |Description

|`KOBITON_APP_ID`
|The ID assigned to the app in Kobiton App Repository.

|`KOBITON_UPLOAD_URL`
|The URL the app binary was uploaded to.

|`KOBITON_APP_PATH`
|The path to the app binary in Kobiton.
|===
