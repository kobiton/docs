= Bitrise integration
:navtitle: Bitrise
// Source: KOB-33032, KOB-33033

Use Bitrise to upload apps to Kobiton App Repository and to run Appium tests on Android and iOS devices in Kobiton Portal. Kobiton publishes two Bitrise steps for this integration:

* *Upload application to Kobiton* uploads an app binary produced by your workflow to Kobiton App Repository.
* *Execute Automation Test on Kobiton* runs an automation test script from a Git repository against a device in Kobiton Portal.

Add each step to an existing Bitrise workflow through Bitrise's workflow editor.
