= Enable Jira Cloud integration
:navtitle: Enable Jira Cloud integration

Connect Kobiton to Jira Cloud so members of your organization can create Jira tickets from xref:session-explorer:manage-sessions.adoc[Session Explorer].

== Before you start

* A Jira Cloud account
* A Kobiton subscription that includes Jira integration

== Enable Jira integration

include::profile:partial$open-settings.adoc[]

. Select *Integration*.
. Under *Issue Tracking*, in the *Jira Integration* card, select *Enable Jira Integration*.
+
image:integrations:integration-jira-enable-jira-integration.png[width=500,alt="The Enable Jira Integration button under Issue Tracking"]

. Select *Confirm*.

If the card shows *Disable Jira Integration*, Jira integration is already enabled.

== Connect your Jira account

Connect your Jira Cloud account with one of these methods:

* xref:_sign_in_from_session_explorer[Sign in from Session Explorer] with your Atlassian account.
* xref:_connect_with_an_api_token[Connect with an API token] in *Settings*.

[#_sign_in_from_session_explorer]
=== Sign in from Session Explorer

. In Kobiton Portal, select *Sessions*, then open a session.
. Select the *Jira* icon in the lower-left corner of the session timeline.
+
image:integrations:jira-create-ticket-integration.png[width=500,alt="The Jira icon in the lower-left corner of the session timeline"]

. In the new browser tab, sign in with your Atlassian account.
. Review the permissions that Kobiton requests, then select *Accept*.

Kobiton confirms that you've signed in to Jira. You can now xref:integrations:jira/create-a-jira-ticket.adoc[create Jira tickets].

[#_connect_with_an_api_token]
=== Connect with an API token

[#_create_jira_api_token]
. Create a Jira API token by following the Atlassian guide to https://support.atlassian.com/atlassian-account/docs/manage-api-tokens-for-your-atlassian-account/[managing API tokens]. Save the token in a secure location.
+
image:integrations:create-jira-api-token-context.png[width=1000,alt="The Create API token button under Security settings"]

. In Kobiton Portal, select your profile name or picture, then select *Settings* and *Integration*.
. Under *Issue Tracking*, in the *Jira Integration* card, select *Connect account*.
+
image:integrations:integration-jira-enable-jira-dc-integration-kobiton-connect-account.PNG[width=1000,alt="The Integration settings page with Jira Integration under Issue Tracking"]

. Select the *Jira Cloud* tab, then enter the following:
** *Host*: Your Jira Cloud site URL, for example `https://<your-site>.atlassian.net`. To find it, open Jira in your browser and copy the address up to and including `.atlassian.net`.
** *User email*: The email address of your Atlassian account.
** *API Token*: The token you created.
+
image:integrations:integration-jira-enable-jira-cloud-integration-popup-closeup.png[width=400,alt="The Jira Cloud connection form with Host, User email, and API Token fields"]

. Select *Connect*.

You can now xref:integrations:jira/create-a-jira-ticket.adoc[create Jira tickets] from Session Explorer.
