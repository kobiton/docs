= Create a Jira ticket
:navtitle: Create a Jira ticket

Create Jira tickets from xref:session-explorer:index.adoc[Session Explorer] and view tickets associated with a session.

Jira integration must be enabled for your organization. See xref:integrations:jira/enable-jira-integration.adoc[Enable Jira Cloud integration] or xref:integrations:jira/enable-jira-data-center-integration.adoc[Enable Jira Data Center integration].

== Open the Jira menu

. In Kobiton Portal, select *Sessions*, then xref:session-explorer:search-for-a-session.adoc[search for a session].
+
image:session-explorer:search-bar-session-criteria-context.png[width=1000,alt="Search for sessions"]

. Select the session to open it in *Session Explorer*.
. Select the *Jira* icon in the lower-left corner of the session timeline.
+
image:integrations:jira-create-ticket-integration.png[width=500,alt="The Jira icon in the lower-left corner of the session timeline"]
+
If you aren't signed in to Jira, a new browser tab opens. Sign in and authorize Kobiton to access your Jira account.

== Create a ticket

. In the Jira menu, select *Create* next to *Create Jira Issue*.
. Select a *Project* and *Issue Type*, then enter a *Title*.
+
The *Description* field is prepopulated with a link to the session and the device details.
+
image:integrations:jira-create-ticket-context.png[width=500,alt="The Create issue form with Project, Issue Type, Title, and a prepopulated Description"]

. Optional: Complete the remaining fields. Available fields depend on your Jira project configuration.
. Optional: Under *Attachments*, select the session logs to attach to the ticket.
. Select *Create*.

A confirmation message appears with a link to the ticket in Jira.

== View tickets created from a session

The number on the *Jira* icon indicates how many tickets were created from the session.

. Select the *Jira* icon.
+
The menu lists each ticket with its title, creation date, and current Jira status.
+
image:integrations:jira-create-ticket-button.png[width=500,alt="The Jira menu listing a ticket created from the session with its status"]

. Select the arrow next to a ticket to open it in Jira. To open all tickets created from the session, select *View all in Jira*.
