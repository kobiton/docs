= TestFlight integration
:navtitle: TestFlight

TestFlight is Apple's app for installing beta builds. Use it to install and test a prerelease build of an iOS or iPadOS app on a Kobiton private or local device. For Apple's instructions on accepting invitations and installing beta builds, see link:https://testflight.apple.com/[TestFlight^].

NOTE: TestFlight isn't available on public devices. Use a private or local device instead. See xref:devices:index.adoc#_device_types[Device types].

== Requirements

* A TestFlight invitation from the app developer, sent as an email invitation or a public link from link:https://appstoreconnect.apple.com/[App Store Connect^].
* A Kobiton private or local iOS device that meets the device and OS criteria the developer set for the beta.
* An Apple Account signed in on that device.

== Start a manual session

xref:manual-testing:start-a-manual-session.adoc[Start a manual session] on a private or local iOS device. Complete the remaining steps on that device.

== Install TestFlight

. Open *App Store* and search for *TestFlight*.
. Install *TestFlight*.

NOTE: The Apple Account on the device doesn't need to match the Apple Account the developer uses in App Store Connect.

== Accept the invitation and install the build

. On the device, open the invitation:
** For an email invitation, open the email and select *View in TestFlight*.
** For a public link, open the link.
. In TestFlight, select *Accept*.
. Select *Install*.
. When the app appears on the home screen, open it to start testing.

== Update to a newer build

When the developer publishes a new beta build, TestFlight sends a notification. To install it, open *TestFlight* and select *Update* next to the app.
